# 뭐든story 아침 시장 브리핑 · 디자인 명세 v1.1

작성 2026-10-07 · 적용: 아침 시장 브리핑 영상 전 회차
관계: `DAILY_VIDEO_PRODUCTION_STANDARD.md`(내용·사실·게시 기준)를 따르고, 이 문서는 **화면·모션·대본 형식·이미지**를 정한다.
기준서 3항(화면)은 이 명세로 대체한다. 두 문서가 충돌하면 사실 정확성 규칙이 우선한다.

매일 영상은 이 명세 + 템플릿 코드 + 에피소드 JSON 스키마의 조합으로만 만든다.
대본 단계(Claude)는 정해진 카드 종류와 필드만 채우고, 화면 배치·색·모션은 템플릿이 결정한다.
그래서 회차마다 디자인이 흔들리지 않는다.

기준 시안: `daily_brief_v2/prototype/` (10/07 원문으로 만든 2분 무음 시안, 장면 10개). 이 시안의 좌표·크기·모션 값이 템플릿의 출발점이다.

## 1. 출력 규격

| 항목 | 값 |
| --- | --- |
| 해상도 | 1920×1080, 16:9 |
| 프레임 | 30fps (카운트업·그래프 모션이 부드럽도록 25fps에서 변경) |
| 길이 | 5~6분 30초 목표. 자료가 적은 날은 짧게, 반복으로 채우지 않는다 |
| 렌더 | 프레임 단위 결정적 렌더(`seek(t)` → 캡처 → ffmpeg). 실시간 화면 녹화 금지 |
| 오디오 | 내레이션 -16 LUFS, true peak ≤ -1.5 dBTP |

렌더 실측(참고): 2분 시안 3,600프레임이 클라우드 작업 컨테이너에서 4분 51초(초당 약 12프레임). 6분 회차면 약 15분으로 추정. 2GB 서버 실측은 별도로 한다.

## 2. 고정 화면 틀 (모든 장면 공통)

좌우 여백 80px. 아래 네 구역은 위치·크기·스타일이 모든 회차에서 같다.

```
y=0    ┌──────────────────────────────────────────────────────────────┐
       │ [로고] 뭐든story 아침 시장 브리핑   요약·시장·이슈·일정   10.07 수 │  상단 바 (0–92)
y=90   ├━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━──────────────────────────────┤  진행선 (3px)
y=120  │                                                              │
       │                      카드 무대 (1760×730)                      │
y=850  │                                                              │
y=868  │                  ┌──── 자막 띠 (최대 2줄) ────┐                │  자막 (868–978)
y=978  │                  └───────────────────────────┘                │
y=1004 ├──────────────────────────────────────────────────────────────┤
       │ [10/06 종가] S&P 500 7,818.93 ▲0.58%  나스닥 …  (왼쪽으로 흐름)   │  티커 (1004–1080)
y=1080 └──────────────────────────────────────────────────────────────┘
```

- **배경**: 남색 방사형 그라데이션 + 옅은 격자 + 60초 주기로 아주 느리게 움직이는 금색 빛 + 아주 옅은 입자 28개. 배경 위에 사진을 깔지 않는다.
- **상단 바**: 로고 마크(책·말풍선, 원본 로고에서 잘라 씀) + "뭐든story 아침 시장 브리핑" / 챕터 알약(현재 챕터만 금색) / 날짜(금색, 요일 포함)와 "자료 기준 HH:MM KST".
- **진행선**: 상단 바 아래 3px 금색 선이 영상 전체 진행률만큼 차오른다.
- **자막 띠**: 실제 음성의 단어 타임스탬프로 맞춘 자막을 화면에 새긴다(무음 시청 대비). 최대 2줄, 한 줄 28자 안팎. 핵심어는 금색.
- **티커**: 그날 원문에 있는 지수·원자재·금리 숫자만. 왼쪽 고정 라벨에 기준(예: "10/06 종가")을 적고 장중 수치는 항목 옆에 "(장중)"을 붙인다. 초당 80px로 일정하게 흐르고, 라벨 오른쪽은 남색으로 서서히 가려 글자가 라벨에 붙어 보이지 않게 한다.
- 샘플·비공개 검토본은 상단 바 오른쪽 아래에 작은 표시("검토용 샘플")를 둔다. 공개본에는 없다.

## 5. 카드 종류 (이 목록 밖의 카드는 만들지 않는다)

주 카드 = 크림 종이 카드(모서리 28px, 그림자). 보조 카드 = 남색 유리 카드(모서리 24px, 옅은 테두리).

**출처 칩**: 원문 문장이 이름을 밝힌 매체·기관만 쓴다(예: CNBC 장중 보도, KRX, Kpler, 골드만삭스). 원문 각주 번호([1], [15])는 시청자에게 의미가 없으므로 화면에 쓰지 않고 `sources.json`과 업로드 설명란에 둔다. 출처 이름이 원문에 없으면 칩 없이 기준 시각만 적는다.
**해석 칩**: 해석 문장에는 "보도 해석"(금색 칩)을 단다.

| 종류 | 언제 | 필드 | 모션 |
| --- | --- | --- | --- |
| `cold_open` | 첫 8~10초. 그날의 핵심 긴장 한 문장 | 질문, 대비 수치 2~3개 | 질문 단어별 등장, 수치 카운트업 |
| `summary3` | 30초 요약 | 카드 3장 × (번호, 그림 패널: 아이콘 2개 + 방향 배지 + 짧은 이름, 제목 2줄, 숫자 칸 2개). 설명 문장은 넣지 않는다 | 카드 0.15초 간격, 아이콘 선 그리기, 배지 팝, 숫자 칸 등장 |
| `market_board` | 시장 대시보드 | 타일 4~8개: 이름, 값, 변화, 기준(종가/장중), 배지(★최고치/장중) | 타일 순차 등장, 숫자 0.9초 카운트업, 배지 팝 |
| `headline` | 이슈 시작 | 이슈 번호, 제목, 기간 태그(당일/수일~수주/수개월), 이미지 | 이미지 천천히 확대(1.00→1.06), 제목 슬라이드 |
| `flow` | 원인 → 해석 → 결과 | 노드 3개: 칩(원인/보도 해석/결과), 아이콘, 핵심 수치 또는 2줄 | 노드 순차 등장, 화살표 선 그리기, 수치 카운트업 |
| `compare` | 이전 vs 이후, 가정 vs 실제 | 두 값, 라벨, 단위, 방향 화살표("하향" 등 원문 표현) | 두 막대 성장 후 곡선 화살표 |
| `bars` | 수급, 종목 등락 | 항목 2~8개(이름, 값, 단위, 짧은 이유), 0 기준 양방향 | 막대 0.8초 성장, 0.1초 간격 |
| `map` | 장소가 의미를 바꿀 때(해협, 항로, 국가) | 영역, 지점, 경로, 지명, 설명 칩 2개 이내 | 지명 등장, 경로 선 그리기 2~3초 + 이동 점, 지점 맥박 |
| `calendar` | 다가오는 일정 | 날짜, 요일, 오늘/내일 배지, 아이콘, 사건, 시각 칩(미확인이면 "시각 미확인") | 줄 순차 등장, 아이콘 선 그리기 |
| `photo` | 실제 대상이 있는 이슈, 개념 설명 | 이미지, 이미지 위 라벨 3개 이내(아이콘+이름+방향), 2줄 설명, 출처/라이선스 칩 | 천천히 확대(13초에 6% 이내), 라벨 팝 |
| `counter` | 다르게 볼 점 (모든 핵심 이슈에 필수) | 아이콘, 근거 수치 1~2개, 한 문장 | 보라 테두리 카드 등장, 수치 카운트업 |
| `signals` | 확인할 신호 | 줄마다: 주제 아이콘, 주제, 조건 알약 1~2개(+로 연결), 화살표, 판단 변화 | 줄 순차, 알약 팝, 점선·화살표 그리기 |
| `glossary` | 처음 나오는 전문 용어 | 용어, 정의(고정 용어집에서만) | 말풍선(로고 모티프) 팝 |
| `closing` | 마지막 8~10초 | `signals`와 같은 줄 + 면책 + 자료 기준 | 순차 등장 후 정지 |

차트·지도·대시보드에는 **그날 원문에 있는 숫자만** 쓴다. 원문에 없는 시계열, 과거 주가 그래프, 추정 막대를 만들지 않는다.
아이콘 속 막대·선은 그림 기호일 뿐 데이터처럼 보이게 축·숫자를 달지 않는다.
지도는 Natural Earth(퍼블릭 도메인) 실제 지리 데이터로 그린다. 손으로 그린 지도 금지. 경로는 "개념도"라고 적는다.

### 5-1. 배치 규칙 (시안 점검에서 확정)

- 막대 길이는 가장 긴 막대 끝에 숫자 라벨(단위 포함)이 들어갈 자리를 남기고 정한다. 막대가 카드 폭의 절반을 넘으면 숫자를 막대 안에 흰 글자로 넣는다.
- 이름 열과 막대 영역을 나눈다. 이름·막대·숫자가 서로 겹치면 불합격.
- 세로 막대의 값 라벨은 막대 위, 항목 라벨은 기준선 아래에 막대 중심과 맞춘다. 차트 위쪽에 라벨이 잘리지 않을 여백을 둔다.
- 카드 아래쪽 빈 공간이 카드 높이의 25%를 넘으면 숫자 칸·출처·보조 띠(예: "수급 변수")를 아래에 고정하거나 카드 높이를 줄인다.
- 지도 지명과 설명 칩이 겹치면 덜 중요한 지명을 뺀다.
- 한 화면의 문장은 카드 제목·자막 외에 2개 이내. 나머지는 아이콘, 숫자, 막대, 지도로 보여준다.

### 5-2. 아이콘 라이브러리

64 격자, 선 굵기 3.6, 둥근 끝, 단색(금색·신호색·방향색) 한 가지 스타일. 남색 둥근 타일 위에 놓거나 그림 패널에 크게 쓴다.
현재 목록: 상승 막대(`chartUp`), 칩, 메모리, 달력, 달력 숫자, 유조선, 문서, 중앙은행 기둥, 기름방울, 번개(전력), ETF 바구니, 시계(만기), 퍼센트(금리), 방패(보호), 계기판(지표), 저울(해석), 체크, 지구.
새 아이콘은 같은 격자·굵기로만 추가하고 이 목록에 적는다. 다른 스타일 아이콘(색칠 아이콘, 이모지, 3D)을 섞지 않는다.

## 6. 모션 규칙

- 등장: 0.5초, 아래 40px → 제자리, 투명도 0→1, 크기 0.98→1. 곡선 `cubic-bezier(.2,.8,.2,1)`.
- 팝(배지·칩·라벨): 0.45초, 크기 0→1 살짝 넘쳤다 돌아옴(back-out).
- 아이콘 선 그리기 0.5~0.9초, 화살표·점선 0.4~0.6초.
- 퇴장: 0.4초, 위로 20px + 투명. 
- 순차 간격 0.12~0.25초. 한 화면에서 동시에 움직이는 요소는 3개까지.
- 숫자 카운트업 0.9초(원문 자릿수·쉼표 유지), 막대 0.8초, 지도 경로 2~3초.
- 챕터 전환: 금색 띠가 0.8초 동안 화면을 가로지르고 상단 챕터 알약이 바뀐다.
- 핵심어 강조는 그 단어가 실제로 발음되는 시각(단어 타임스탬프)에 맞춘다.
- 카드와 글자는 다 나온 뒤 정지한다. 계속 움직이는 것은 배경(빛·입자), 지도 지점 맥박, 일러스트 안의 작은 불빛뿐이다. 회전·뒤집기 전환은 쓰지 않는다.
- 사진·일러스트는 카드 안에서만 움직인다(확대 6% 이내).

## 7. 회차 구성 (장면 문법)

| 순서 | 챕터 | 길이 | 카드 |
| --- | --- | --- | --- |
| 1 | 오프닝 | 8~10초 | `cold_open` |
| 2 | 요약 | 25~30초 | `summary3` |

| 7 | 마무리 | 8~10초 | `closing` |

YouTube 챕터는 2~7의 시작 시각으로 자동 생성한다.

## 8. 대본 규칙 (시청자 기준)

1. 첫 문장은 그날 원문 요약 1번에 근거한 **질문 또는 대비** 한 문장. 인사·로고 소개로 시작하지 않는다.
2. 한 문장에 정보 하나, 40자 안팎. 이슈마다 **무슨 일 → 왜 중요 → 다르게 볼 점 → 확인할 신호** 순서.
3. 숫자는 이슈당 2~3개만 말하고 나머지는 카드에 둔다. 말로 하는 숫자도 원문과 같아야 한다(반올림·"넘게" 같은 바꿔 말하기 금지, 띄어쓰기만 허용: 1조7,491억원 → 1조 7,491억원).
4. **원문에 없는 계산 금지.** 차이·비율·합계·환율 환산·기간 수익률을 새로 계산해 화면·자막·내레이션에 쓰지 않는다. 원문이 직접 쓴 비교(예: "약 23% 적었다", "112조원→106조원")만 쓴다.
5. 부호는 말로 읽는다: "+0.58%" → "0.58% 올랐습니다", "-6.39%" → "6.39% 내렸습니다". 단위·약어는 발음 사전을 따른다.
6. "그래서 무엇이 달라지나"는 원문의 해석 문장 범위 안에서만 말한다. 원문에 없는 전망·추천·목표가를 만들지 않는다.
7. 과장어 금지("충격", "폭락" 등). 원문이 "급락"이라고 쓴 경우에만 그 표현을 쓴다.
8. 원문의 "보도 해석"과 내부 분석 해석을 구분해 화면 칩으로 표시한다. 내부 명칭("Analyst")이나 AI 관련 문구는 화면·자막·제목·설명 어디에도 쓰지 않는다.
9. 날짜에는 요일을 붙이고 달력으로 확인한다(예: 2026-10-07 수, 10-08 목).
10. 마무리에 "투자 권유가 아닙니다"와 자료 기준 시각을 넣는다.

- 모든 이미지는 `assets/manifest.json`에 파일명, 태그, 출처 URL, 저작자, 라이선스, 검수일을 기록한다. 출처 표기가 필요한 이미지는 업로드 설명란에도 적는다.
- 라이브러리 태그: 미국증시, 금리·채권, 연준, 환율, 금, 원유·해운, 반도체·메모리, AI·데이터센터, 전력·원전, 한국증시, 수급, 무역·관세, 조선, 미디어·콘텐츠, 2차전지, 헬스케어. 태그당 3장 이상 확보해 같은 그림이 연속으로 나오지 않게 한다(직전 3회차와 겹치면 다른 컷).
- 서버 자동 제작은 라이브러리(미리 받아 둔 파일)만 쓴다. 매일 인터넷에서 새 사진을 찾지 않는다.

## 12. 에피소드 JSON (대본 단계 출력)

```json
{
  "date": "2026-10-07", "weekday": "수", "asof": "10:31 KST", "source_digest": "…",
  "ticker": {"label": "10/06 종가", "items": [{"name": "S&P 500", "value": "7,818.93", "change": "+0.58%", "dir": "up", "claims": ["c3"]}]},
  "scenes": [
    {"chapter": "오프닝", "type": "cold_open", "question": "…", "stats": [ … ], "narration": "…", "claims": ["c1"]},
    {"chapter": "요약", "type": "summary3", "cards": [{"icons": [["chartUp","up"],["memory","down"]], "icon_names": ["미국 지수","메모리·저장장치"], "title": "미국은 최고치,\n메모리는 약세", "stats": [{"label": "S&P 500 · 10/06", "value": "0.58%", "dir": "up", "claims": ["c3"]}]}]},
    {"chapter": "핵심 이슈", "type": "bars", "title": "…", "items": [{"name": "외국인", "value": -17491, "label": "−1조 7,491억", "unit": "억원"}], "source": "KRX", "narration": "…", "claims": ["c22"]},
    {"chapter": "마무리", "type": "closing", "rows": [{"icon": "percent", "topic": "금리", "if": ["의사록 긴축 강조", "장기금리 반등"], "then": "주가의 금리 지지 재평가", "claims": ["c9"]}]}
  ]
}
```

- `type`은 5장의 목록만, 아이콘은 5-2 목록만 허용한다. 필드 길이(제목 18자, 카드 제목 2줄, 조건 알약 16자 등)는 스키마에서 검사한다.
- 모든 숫자 필드는 원문 주장 ID(`claims`)를 가져야 하고, 검사기가 원문 문자열과 대조한다. 표시용 라벨(`label`)도 원문 숫자와 같아야 한다.
- 렌더러는 이 JSON만 읽는다. 대본 단계는 HTML·CSS·좌표를 직접 만들지 않는다.

값이 0인 막대(예: 휴장)는 막대 없이 회색 라벨로만 쓴다. "보도 해석" 칩은 남색 카드 위에서 금색 글자로 쓴다.
