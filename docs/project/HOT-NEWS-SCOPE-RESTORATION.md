# Reporter 뉴스 범위 복원

2026-09-21 KST. 사용자가 공식 발표만 수집하는 구현이 최초 요청과 다르다고 지적했다.
`hot-news`의 목표를 경제·금융, 거시경제, 세계 정세, 무역·에너지·공급망,
파급력 큰 기업·산업·기술, 글로벌 주요 사건으로 복원한다. 한국 및 해외 주요 지역을 포함하고,
시장 반응이 즉시 나타나지 않는 중대한 국제 사건도 대상으로 삼는다.
정기 브리핑은 `daily-brief`의 별도 과제이며, 이 채널은 새 사건을 확인한 뒤 계속 전달한다.

사용자의 비용 결정은 **“추가 비용 없이 기존 구독·무료 소스 우선”**이다.
유료 뉴스 API·GNews·신규 서버를 구매하지 않았다. RSS와 기존 ChatGPT 구독의 검색을 사용한다.

## 소스와 범위

무료 언론 RSS 9개(BBC 3개, KBS World 2개, CNBC 4개)와 기존 공식 피드 6개를 등록했다.
같은 매체의 섹션들은 하나의 보도 원천이다. 총 15개 피드는 독립 매체 15개를 뜻하지 않는다.
공개 RSS의 개인 뉴스 읽기 범위에서 짧은 사실 요약과 출처 링크를 소유자의 Slack에 전달한다.
기사 전문·사진·영상의 재배포나 모델 학습을 하지 않으며, 상업적 콘텐츠 라이선스 취득을 주장하지 않는다.
자동 수집 제한을 확인한 매체와 차단·로그인·유료 페이지는 우회하지 않는다.

| 요청 영역 | 등록 소스 | 09:28 KST 실제 자료 검사 |
|---|---|---|
| 경제·금융 | CNBC 금융·경제, BBC 경제, KBS 경제 | CNBC의 관세·연료비·금리 부담 기사 RSS·본문 확인 |
| 거시경제 | CNBC 경제·금융, BBC 경제, 연준·ECB·BEA | 금리·경제 기사 경로 확인. 그 시점 새 공식 통계 발표 없음 |
| 세계 정세 | BBC 국제, KBS 전체, CNBC 국제 | 독일 주 선거와 한국 안보 관련 기사 확인 |
| 무역·에너지·공급망 | CNBC 국제·금융·경제, KBS 경제 | 미중 경제 당국 회담 및 관세·연료비 기사 확인 |
| 기업·산업·기술 | CNBC 기술, BBC 기술, KBS 경제 | 한국 반도체 고용, 엔비디아·AI 정책 기사 확인. BBC 기술은 24시간 내 기사 0건 |
| 글로벌 주요 사건 | BBC 국제, KBS 전체, CNBC 국제 | 분야가 열려 있고 국제 기사 유입 확인. 재난·보건 등 하위 분야의 실제 게시 인수는 아직 없음 |

이는 특정 시점의 연결·기사 존재 검사다. 분야별 모든 중요 사건의 수집이나 누락률을 입증하지 않는다.
[운영 지역 실제 RSS·본문 검사](evidence/hot-news-scope-source-probe.json): 15개 피드 모두 성공,
언론 9개 중 8개에서 최근 24시간 기사를 확인했다. 8개 피드의 표본 기사 본문 추출에 성공했다.
BBC 기술은 오래된 기사만 있어 최신 뉴스 표본으로 대체하지 않았다.

## 편집·수집 변경

- 일반 보도는 등록된 매체 원문과 실제 인용을 확인한 뒤 `보도` 및 매체 귀속을 표시한다.
  의혹·익명 주장·피해 규모·예측·의견은 이 단일 매체 경로에서 제외한다. 독립 확인은 서로 다른
  실제 원천 2개 이상을 요구하며, 전재와 정부의 상대국 주장은 그대로 사실 확정하지 않는다.
- 소스별 10분 수집과 5분 편집을 유지한다. 같은 매체의 섹션 간 중복을 줄이고, 편집 입력은
  원천별로 섞어 한 매체가 일괄 검토를 차지하지 않게 한다.
- KBS의 옆 홍보 영역을 본문으로 읽던 오류를 수리했다. 실제 `body_txt` 기사 영역을 요구한다.
  JSON-LD 발행 시각·기자 표시를 수집하고 명시된 구독 전용 기사는 제외한다.
- 추가 검색은 30분 간격, 결과 최대 6개다. 6개 분야를 순환하며 최근 보류 기사 최대 2건의
  추가 보도도 찾는다. 검색 스니펫은 게시 근거가 아니다. 등록 매체 URL만 후보로 저장하고
  수집기가 공개 원문과 실제 발행 시각을 확인한다. 발행 시각을 현재 시각으로 채우지 않는다.
- 검색도 PostgreSQL에 요청·응답·예산을 저장하고 Temporal에서 실행한다. 사용자 업무를
  우선하며 편집·기존 직원과 한 모델 작업 슬롯을 공유한다. 결과 불명 호출은 새 ID로 재실행하지 않는다.
- 상태 조회에서 RSS 성공, 새 기사, 편집 보류·제외, 실제 Slack 전달, 분야별 소스와 검색 상태를
  구분한다. 분야 등록과 최근 기사 수는 해당 분야의 충분한 취재를 보증하지 않는다.

실제 PostgreSQL·Temporal 회귀 검사는 **479 passed, 2 skipped, 1 live deselected**, lint 통과다.
모델·Slack은 이 회귀 검사에서는 모의이며 실제 구독·Slack 검사는 별도 기록한다.
[회귀 검사](evidence/hot-news-scope-tests.json).

## 실제 구독 미리보기

운영 서버의 일회용 PostgreSQL에서 실제 기사 6건을 gpt-6-astra/high 구독 모델로 검토했다.
독일 총리 발언·미중 회동·한국 반도체 고용 3건은 미리보기 게시 대상, 북한 발사 보도와
엔비디아 AI 정책 영향력 기사는 추가 근거·시각·주장 범위 때문에 보류, 기업 비용 부담
기획 기사는 새로운 사건으로 보기 어려워 제외했다. 무료 매체 기사를 무조건 게시하도록 만들지 않았다.
추가 검색도 실제 네이티브 검색을 수행했고 등록 매체 후보만 저장했다. outbox는 0건이며
영수증 보존 후 일회용 DB를 삭제했다. [실제 구독 검토](evidence/hot-news-scope-codex-preview.json).

기존 서버에 배포하고 09:43 KST에 수집·편집·검색을 활성화했다. 실제 구독 미리보기의 패키지
파일 해시는 이 커밋과 일치한다. 최종 이미지에서도 15개 피드 및 최신 언론 표본 8개를 확인했다.

지역별 누락률·장시간 가용성·중요도 판단의 정확도는 이번 연결 인수만으로 확정하지 않는다.
뉴스 원천은 BBC·CNBC·KBS 중심이며, 모든 국가·사건을 포괄한다는 뜻이 아니다. 거시 통계 및
재난·보건 등 하위 분야의 새로운 실제 사건은 발생 시 추가 관찰한다. 일정 브리핑이나 뉴스
건수 채우기는 추가하지 않았다.
