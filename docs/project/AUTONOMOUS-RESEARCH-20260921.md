# 지속형 자율 연구 — 구현과 인수 범위

구현 승인: 사용자의 “Implement the plan.”, qws 계약 `fcec7879dbf7`.
현재 단계는 검토 가능한 구현·실행 환경 준비다. 운영 활성화와 새 경제 실험은 아직 하지 않았다.
설계 정본: [ADR 0031](../adr/0031-persistent-autonomous-research.md).

## 직원들이 실제로 하는 일

1. 연구 담당자가 출처·예상 효과·반증 조건을 갖춘 가설을 낸다.
2. 금융전략 담당자가 독립된 문맥에서 구체적인 반론과 검사 방법을 낸다.
3. 총괄이 그 반론을 인용해 가설 수정 또는 실행을 선택한다.
4. 개발 담당자가 승인된 파일만 수정한다. 서버가 정확한 파일 전후 내용으로 Git 커밋을 만든다.
5. 3070이 자격 검사 후 개발구간을 실행한다. 코드·설정·입력·호스트·실행 식별자와 결과 파일을 보존한다.
6. 연구 담당자가 직전 결과를 해석한다. 이번 연구의 위험제약을 지킨 최선을 별도로 보존한다.
7. 구현과 분리된 검증 담당자가 현재와 과거 보고 대상의 실제 파일을 읽고 감사한다.
   서버가 고정한 qlab 코드로 감사 파일과 범위를 검증한 뒤 HTML·출처를 발행한다.
8. 총괄이 이전 결과와 반론에 근거해 다음 가설 또는 대기를 결정한다.

가설·반론·선택의 핵심 본문은 같은 연구 스레드에 남긴다. 감사 전 성과는 내부 연구 문맥에만
있으며 일반 대화·공유 지식·Slack 성과 보고에는 노출하지 않는다. 최종 보고와 승인 요청은
총괄이 소유자를 태그한다. 개발·검증 직무의 내부 배치는 새 Slack 계정 설치를 요구하지 않는다.

## 지속성과 권한

PostgreSQL이 목표·승인·가설·반론·선택·시행·해석·최선·감사·발행을 저장하고, Temporal이
직원 호출·타이머·재개를 맡는다. 직접 맡긴 업무는 자율 후속 업무보다 우선한다. 이미 실행
중인 실험은 강제 선점하지 않는다. 구독 한도와 워커 오프라인은 대기 상태로 보존한다.

기술 실패 횟수로 연구를 소진시키지 않는다. 같은 실패를 그대로 재실행하려면 새 검증 근거가
있어야 하며, 실행 상태가 불명확하면 먼저 대사한다. 과학 시행은 별도 동결 예산으로 센다.
새 이름만 붙인 동일 설정은 새 시행으로 실행하지 않는다. 탐색 범위를 다 쓰면 새 명세를 기다린다.

승인은 소유자·스레드·개정·전체 명세 해시에 묶는다. 짧은 승인, 버튼, 중복, 오래된 승인과
모호한 대상의 처리를 검사한다. 모델의 말은 승인으로 쓰지 않는다. 명세 전체를 승인 메시지에
제시하며, 새 비용·데이터·위험·탐색 범위는 다시 승인해야 한다.

직원 프롬프트에는 전문 절차와 해당 직원·모델·effort의 평가 피드백을 포함한다. 반복되는
계약/실행 오류는 기존 개선 BOT에 접수한다. 회사 코드를 바꾸는 경우 기존 수정·테스트·PR과
운영 검토 절차를 유지한다.

## 검증 범위

- 실제 일회용 PostgreSQL: 승인·대기·우선순위·중복·읽기 영수증·시행과 발행 상태.
- 실제 로컬 Temporal: 단계 실행, 작업자 재시작 후 재개와 저장 이력 replay.
- 실제 Git·qlab: 제한된 패치, 커밋·번들, 독립 감사 파일 검증, CSV에서 HTML 생성,
  승인된 출처를 총괄이 소비하는 경로. 모델 응답·Slack/S3 전송은 이 검사에서 fixture다.
- 실제 3070 Linux: Git 패치 → 분리 실행기 → bubblewrap 자격 검사/평가 → 엄격한 결과 ZIP
  소비. 승인된 입력·런타임만 노출하고 네트워크·호스트 홈·비밀 환경·Git 이력을 차단했다.
  업로드 응답 유실 후 같은 바이트 재전송과 poller 재구성 후 중복 실행 차단을 검사했다.
  이 검사는 합성 자료를 사용하며 새 과학 시행 수는 0이다.

상세 영수증과 최종 검사 결과는 [이번 인수 증거](evidence/autonomous-research-20260921/)에 남긴다.
Linux protocol fixture는 실제 Slack·구독 모델 검사가 아니다. 과거 고정 P11의 실제 Slack
성공 기록을 이번 자율 연구의 성공 기록으로 대신하지 않는다.

## 첫 연구와 남은 인수

첫 대상은 기존 P11 국내 ETF의 여섯 가지 피처 변형이다. 포트폴리오·비용·데이터 기간은
고정하고 이전 관찰과 독립 반론으로 다음 변형을 선택한다. 후보를 전부 돌려도 새로운 탐색
범위가 자동으로 생기지 않는다. 원래 M2/C02 출처는 보존하며, 이번 연구 안의 최선과 별개다.
기준선 자료의 미확인 문제를 해결하지 않은 상태에서 초과성과를 계산하거나 주장하지 않는다.

운영 반영 검토 후 첫 명세를 실제 Slack에서 승인받는다. 서로 다른 실험 최소 2회와 실제
직원 응답, 이전 결과에 따른 후속 선택, 최선 보존, 독립 감사·보고·후속 연결을 확인해야
첫 자율 연구 인수가 끝난다. 현재 그 인수는 **미수행**이다.

이 구현은 국내 ETF 개발구간 경로다. 글로벌·가상자산 실행, 고빈도 운용, live 자본배치,
어떤 공개 시스템보다 우수한 성과는 이번 검증 범위에 포함되지 않는다.
