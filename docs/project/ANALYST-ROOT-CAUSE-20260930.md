2026-09-30. 기존 INTENT-v16의 Analyst 품질 개선을 이어 진행한 기록이다.
Quant Scout의 수집·연구 기능은 이번 변경 대상이 아니다.

## 실제 새 오전판

9월 30일 오전판은 오전 7시 KST 이전에 실제 수집된 원문만 사용했다.
96개 후보에서 실제 모델이 16개 원문을 선택했다. 원문과 정책, 입력, 실제 모델 영수증을
[평가 기록](evidence/briefing-analyst-root-cause-20260930/am-20260930/source-manifest.json)에 보존했다.
수집 원문 외의 검색 결과를 과거 평가 입력으로 보충하지 않았다.

독립적인 원문 점검을 먼저 작성하고 실제 작성 결과와 대조했다.
[첫 본문](evidence/briefing-analyst-root-cause-20260930/am-20260930/draft/brief.md)은
미국 주요 지수·시장 내부 차이, 금리·소비·PCE 전망, 원유 공급과 협상·제재, AI 투자,
의약품 관세, 한국 전일 수급·환율·채권을 다룬다. 핵심 미국 지수 3개는 독립 근거가 있다.
작성 성공만으로 전문가 품질을 인정하지 않는다.

[첫 검증](evidence/briefing-analyst-root-cause-20260930/am-20260930/independent-main-audit.json)에서
5개 항목이 제외됐으며 원인을 구분했다. 한국 전일 종가 2개와 환율 1개는 정상적인 제외다.
나머지는 정확한 원문 변환의 오탐이다. `2026.9.29`가 소수로 읽혀 월·일을 인식하지 못했고,
`two or three tenths of a percentage point`의 첫 끝값 0.2를 인식하지 못했다.
이 첫 실패는 삭제하지 않는다. 현재 입력과 검증기를 유지한 실제 검토·수정 결과를 별도로 남긴다.

실제 첫 의미 검토는 **8/12**였다. 수치·출처·시점·인과 구분·전달 경로·대안·다음 조건·
가독성은 통과했지만 중요성·반대 근거·포괄성·깊이는 실패했다. 검토자가 요청한 원문 2개,
총 5,677자를 남은 예산 안에서 추가해 한 차례 수정을 실행했다.
[추가 원문 독립 점검](evidence/briefing-analyst-root-cause-20260930/am-20260930/independent-supplement-audit.json)은
LNG 속보에 투자 확약·조건이 없고, AMD 방한 일정·회동도 확정 상태가 아님을 확인했다.
LNG 속보의 주변 영역 혼입은 실제 원문 처리 버그이며 위의 수집기 수정으로 막았다.
[원문 처리 검사](evidence/briefing-analyst-root-cause-20260930/original-body-regression.json)는
HTML fixture를 포함해 51개 통과했다. 이것은 서버 수집기에 실제 설치했다는 뜻은 아니다.

고정된 검증 31의 수정본은 여전히 2개 항목에서 실패했다.
소비 이슈의 범위 수치는 같은 오탐이었지만 한국 개요는 별도 실제 오류였다.
0.66% 개장 하락을 설명하면서 그 숫자가 있는 문단을 해당 항목의 인용에 포함하지 않았다.
다른 원문 문단에 사실이 있어도 항목별 근거가 빠지면 정상적으로 거절해야 한다.
[고정 평가 실패](evidence/briefing-analyst-root-cause-20260930/am-20260930/frozen-case-outcome.json)를
보존하고, 검증 32와 같은 원문을 이용한 별도 개발 수정·검토를 기록한다.
이 개발 결과는 새 날짜의 독립 검증 통과로 세지 않는다.

[개발 정책](evidence/briefing-analyst-root-cause-20260930/am-20260930/development-v32/policy.json)은
최대 2개 완료 호출, 추가 원문 없음, 실제 12개 항목 검토와 독립 본문 대조를 명시한다.
수치 변환 수정 후 관련 테스트 122개가 통과했고 실제 한국 개요 근거 누락은 여전히 거절됐다.

개발 수정 응답은 한국 개요의 인용 누락을 고쳤지만 전일 한국 종가 2개를 다시 표로 제공했다.
기존 검증 32 결과와 입력 초과 기록은 보존했다. 검토 입력은 90,506자여서 88,000자 한도를
넘었다. 줄바꿈 보정 가설은 실제 입력을 줄이지 못해 실험 변경을 되돌렸다.
독립 검토의 완전한 12개 기준과 모든 원문·본문을 유지하고, 중복된 작성 playbook 및
JSON 스키마의 표시 이름만 제거했다. 작성 모델은 완전한 Analyst playbook을 계속 받는다.

전일 종가를 정확하게 표시할 수 있도록 운영 생산자가 전일 거래소 마감 시각을 고정하고,
소비자가 날짜·시각·근거를 확인하는 경로를 추가했다. 고정 시각이 없거나 다르면 거절하며
해당 전일 값에 임의의 전기 대비 계산을 붙이는 것도 거절한다. PostgreSQL 생산자 검사와
본문의 명시적 날짜 표시 검사를 통과했다.
[개발 입력 변경 기록](evidence/briefing-analyst-root-cause-20260930/am-20260930/development-v32/v33/input-amendment.json)은
형식 14·검증 33, 추가 시장 원문·가격 없음, 실제 검토 입력 **87,823자**, 기계 제외 **0개**를
명시한다. 6개 주요 이슈와 한국·미국 지표가 본문에 남았다.
[독립 본문 점검](evidence/briefing-analyst-root-cause-20260930/am-20260930/development-v32/v33/independent-main-audit.json)을
실제 의미 검토 결과를 보기 전에 작성했다. 최초 고정 평가의 실패를 이 개발 결과로 덮지 않는다.

## 반복되는 누락의 구조적 원인

같은 18개 원문을 이용한 후속 개발 검토는 **9/12**, 이후 **10/12**였다.
전일 한국 지표를 시간·날짜와 함께 표시하고 실제 경유 가격과 중재 접촉을 본문에 보완했다.
검증 34는 전일 환율을 종가로 표현하지 않고 정확한 고정 시각의 `한국 전일 참고`로만 허용한다.
검토 입력은 원문·본문·12개 기준을 모두 유지한 **87,874자**였다.
[10/12 실제 검토](evidence/briefing-analyst-root-cause-20260930/am-20260930/development-coverage/v34/reviewed/assessment.json)는
중요성·포괄성만 실패했고 가독성·깊이·반대 근거는 통과했다.

원문과 각 수정본을 대조하니 전체 재작성이 기존에 맞게 들어 있던 중요한 사실을 삭제했다.
물가 수정 폭 0.2~0.3%포인트, 호르무즈 통과량의 전쟁 전 대비 기준, 경유 수출 제한 규모가
그 예다. AMD 일정만 확인 대상으로 남기고 이미 체결된 협력의 내용도 놓쳤다.
지침을 더 길게 쓰는 것만으로는 이런 교체 누락을 막지 못했다.

검증 35에서 **검증된 초안에 부족한 사실만 추가하는 typed patch**를 도입했다.
기계·의미 오류가 없고 가독성·정확성·시점 등의 기준이 통과했을 때만 이 경로를 선택한다.
기존 문장·인용·가격·일정·다음 확인 조건을 그대로 보존하고, 검토가 지적한 원문의 관련
본문 항목에만 추가한다. 총 문장 길이·인용 수·출처·수치를 다시 확인하고 전체 결과를
독립 검토한다. 잘못된 기존 주장은 전체 수정 경로를 유지한다. 당시 가독성 수정도 전체 수정 경로였으나,
아래 검증 37에서 정확한 기존 초안의 가독성 수정은 문장별 수정으로 확장했다.
[별도 개발 정책](evidence/briefing-analyst-root-cause-20260930/am-20260930/development-append/policy.json)은
최대 2개 완료 호출과 추가 원문 금지를 모델 실행 전에 고정했다.
실제 수정 호출은 37.554초, 출력 979토큰이었다. 앞선 전체 재작성은 696.445초,
출력 22,825토큰이었다. 이는 같은 실행 조건에서 확인된 두 호출의 기록이며 반복 성능 보장은 아니다.
기존 본문에서 변경된 항목은 PCE·원유·AI의 세 문장뿐이었고 가격·일정·확인 조건은 동일했다.

실제 출력에서 정확한 `kilobarrels`→배럴 단위 변환이 기계 검사에 걸렸다.
검증 35의 실패를 보존하고 검증 36에서 명시적 단위와 같은 문장 내 전쟁 전 기준의 단위를
정확히 확장했다. 다른 문장·퍼센트·다른 단위에는 확장하지 않는다.
추가 사실을 모두 살린 검토 입력이 88,361자로 초과한 기록도 남겼다. 검토에 필요 없는
미사용 지표 정의만 제외하고 사용 지표의 이름·단위·시장 정의는 전부 유지했다.
최종 검토 입력은 **87,948자**이며 전체 18개 원문과 모든 본문·12개 기준을 포함한다.
[독립 불변성·본문 대조](evidence/briefing-analyst-root-cause-20260930/am-20260930/development-append/v36/independent-main-audit.json)를
실제 최종 검토 전에 기록했다. 최종 실제 의미 검토는 **11/12**였고 기계 제외·인용 충돌은 0개였다.
보완 대상 사실은 모두 본문에 남아 중요성·반대 근거·깊이·가독성을 통과했다.
다만 제재 대상의 중국·홍콩 전자부품 조달 지원망이 빠졌다고 포괄성을 다시 거절했다.
[최종 개발 실패](evidence/briefing-analyst-root-cause-20260930/am-20260930/development-append/v36/outcome.json)를
보존한다. 최대 2개 완료 호출을 사용했으므로 추가 재작성을 이어 합격할 때까지 반복하지 않았다.
이 실험 역시 같은 원문을 사용하므로 새 날짜의 통과로 세지 않는다.

## 운영 상태

[최초 서버 조회](evidence/briefing-analyst-root-cause-20260930/runtime-calendar-probe.json)에서
최초 조회 시 릴리스 링크는 `f1947f4bf22471816a352ec848d373c4d6d97267`였다. Analyst 앱 자격 정보의
존재만 확인했고 비밀 값은 출력하지 않았다. 역할·채널·예약·발송은 활성화되지 않았다.

[설치 정책 검사](evidence/briefing-analyst-root-cause-20260930/installed-release-gate.json)는
이전 확정 커밋 `4f85bfcc`를 그대로 적용하면 `release_file_deleted`로 거절한다.
1,087개 변경에는 현재 서버의 기능·배포 파일 삭제가 포함된다. 이 기록은 이번 미커밋 변경의
설치 검사나 실제 배포를 뜻하지 않는다. 현재 서버 기능을 보존하는 통합 후보가 필요하다.
[통합 원인 점검](evidence/briefing-analyst-root-cause-20260930/release-integration-diagnosis.json)은
현재 서버가 별도 개발 브랜치 계열에 있으며 직접 대체 후보에 247개 파일 삭제가 있음을 확인했다.

작업 중 다른 운영 변경으로 릴리스 링크가 달라졌다.
[07:54 UTC 실제 프로세스 조회](evidence/briefing-analyst-root-cause-20260930/runtime-release-identity-0754.json)에서는
링크가 `5defb8cb`였으나 일반 worker 이미지는 `0286ba3e`, news-worker는 `837ac72a`였다.
링크와 환경 변수의 커밋을 실행 중인 프로세스 버전으로 간주하면 안 된다.
[새 링크 기준 검사](evidence/briefing-analyst-root-cause-20260930/release-gate-0754.json)도
이전 확정 커밋의 직접 적용을 거절했다. 변경 1,113개와 보호 파일 19개를 확인했다.
후속 통합은 실제 서비스 이미지별 기능을 보존하는 후보에서 검사해야 한다.
[관측 커밋의 파일 조회](evidence/briefing-analyst-root-cause-20260930/release-feature-presence.json)에서
릴리스 링크와 news-worker 이미지 라벨의 소스 트리에는 `src/quant_company/briefing`과
Analyst 앱 정의가 없었다. 주소나 활성화 플래그만 고쳐서는 이 기능이 설치되지 않는다.
이는 이미지 파일시스템 자체의 완전한 검증은 아니며 그 범위도 기록에 명시했다.
이 조회는 배포나 최신 미커밋 후보의 설치 검사가 아니다.

공유된 구독 모델 실행 통로는 실제로 여러 차례 `busy`를 반환했다.
확실히 실행되지 않은 호출만 동일 요청 ID로 재시도했고 다른 작업을 중단하지 않았다.
정시 운영에서는 내용 품질 외에 이 통로의 대기 시간도 확인해야 한다.

BLS의 공식 HTML·목록·ICS 형식은 서버에서 모두 HTTP 403이었다. 공식 대체 형식도
동작하지 않으므로 형식만 바꿔 일정 문제를 해결했다고 주장하지 않는다.

## 저녁판에서 재현된 손실과 문장별 수정

고정한 저녁판의 한 차례 전체 수정은 598.666초가 걸렸다. 전체 20개 원문을 사용하는
수정본은 기계 제외·인용 충돌이 없었으나 실제 최종 검토는 **9/12**였다. 중요성·포괄성·
가독성이 실패했다. 바이오 약세, 채권 하락의 전일 과잉 반응 되돌림, 경유 사용 제한의
대안, 분기 외환 순매도 비교, 실제 카드 소비의 변화가 빠졌다. 본문 앞에 수급보다
집계 충돌·NXT·잠정치 설명이 나와 읽는 흐름도 악화됐다.
[사전 고정 평가의 실패](evidence/briefing-analyst-root-cause-20260930/pm-20260930-v36/frozen-case-outcome.json)를
그대로 보존했다. 5개 완료 호출을 썼으며 두 번째 수정을 실행하지 않았다.

**검증 37의 EditorialPatch**는 정확한 기존 초안에서 가독성 개선이나 추가 고정 원문이
필요할 때 본문 문장만 고친다. 기존 ID·종류·인용과 수정하지 않는 문장은 서비스가 유지한다.
가격·일정·제목·요약·인과 경로·대안·다음 확인 조건은 수정할 수 없다. 기존 숫자를
삭제하면 서비스가 거절한다. 이미 반영된 중요 사실의 목록도 모델에 제공해 의미를
보존하도록 요구하되, 의미 보존 자체는 기계적으로 보장하지 않으며 전체 독립 검토가 필요하다.
오프라인 평가도 운영 저장소와 동일하게 추가 원문을 포함한 묶음에서 검증하도록 고쳤고,
실제 PostgreSQL 왕복·추가 원문·재실행·오프라인 일치 검사를 통과했다.

같은 저녁 원문에 검토가 요구한 고정 원문 3개만 더하는 별도 개발 정책을 먼저 고정했다.
23개 원문 41,017자로 42,000자 예산 안이며, 수정 입력 81,909자로 한도를 지켰다.
공통 허용 출처 목록을 한 번만 제공해 중복을 줄였고 원문·허용 권한을 줄이지 않았다.
실제 문장별 수정은 **171.468초**에 완료됐지만 검증에서 두 항목을 제외했다.
이는 서로 다른 입력의 개별 관측이며 일반적인 속도 향상을 입증하는 비교 실험은 아니다.

외환 문장은 원문의 음수 순거래를 양의 순매도 규모로 표현했지만 현재 수치 검증기가
이 형태의 부호 변환을 지원하지 않는다. 원유 문장에 새로 넣은 ‘29일’은 해당 문장의
인용에 없었다. 원문 다른 위치에 날짜가 있어도 문장별 근거 누락은 실제 오류다.
[개발 실패 기록](evidence/briefing-analyst-root-cause-20260930/pm-20260930-v36/development-v37/outcome.json)에
분리해 남겼다. 잘못된 부분을 제거한 축약본으로 품질 합격을 얻으려 하지 않았으며,
