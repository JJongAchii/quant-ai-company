# 브리핑 내용 평가 — 2026-09-22

이 문서는 실제 모델 출력을 받기 전에 정한 평가 기준이다. 코드 테스트나 합성 예시의 문장 길이를
애널리스트 수준의 증명으로 삼지 않는다. 실제 구독 모델, 원문, 요청 ID, 결과와 실패를 보존한다.
Slack에 게시하거나 운영 설정을 바꾸지 않는 평가다.

## 기준

| 항목 | 수용 기준 | 실패 예 |
|---|---|---|
| 사실·숫자·시각 | 원문과 일치하고 종가/장중/과거 자료 구분 | 장중 반등을 전날 종가로 표시, 없는 예상치 |
| 오늘의 큰 그림 | 시장 방향, 상승/하락의 범위, 자산 간 흐름과 긴장 관계 설명 | 지수 두 개와 헤드라인만 나열 |
| 중요 이슈 | 원문 묶음의 핵심 시장·정책·정세·기업 이슈를 다루거나 제외 이유 기록 | 전쟁/정책 변화가 입력에 있는데 누락 |
| 분석 | 확인된 사건 → 구체적 영향 경로/대상 → 해석을 바꿀 관측 연결 | 모든 이슈가 막연한 변동성/모니터링으로 끝남 |
| 불확실성 | 발언·보도·시행·가격 반응 구분, 반대 근거를 결론에 반영 | 협상 제안을 합의/해협 재개로 단정 |
| 가독성 | 핵심 요약 뒤 읽을 만한 문단, 본문만으로 당일 상황 이해 | 같은 문장 반복, 내용이 스레드로 밀려 사라짐 |

사실/시점의 중대한 오류 또는 핵심 사건 누락은 평균 점수로 상쇄하지 않는다. 글자 수는 진단값이며
통과 점수가 아니다. 조용한 날은 짧아도 되며, 사건이 많은 날을 세 이슈로 제한하지 않는다.
기계 검증, 작성 모델과 분리된 의미 검토, 다른 구독 모델의 비식별 평가를 구분한다.
모델 평가자는 인간 전문가가 아니며, 소수 사례 통과를 전문가 인증/예측력으로 부르지 않는다.

## 사례와 비교

- 실제 AM: 기존 수집 기록 중 09/22 07:10 KST 이전에 발행·수집된 원문만 사용.
- 실제 PM: 09/22 장 마감 이후 실제 수집 시각의 스냅샷. 정시 20:00 발간의 검증으로 부르지 않는다.
- 동일한 실제 입력으로 이전 작성 지침과 새 작성 지침 비교. 모델 평가에 작성자/버전 이름과 이전 점수는 숨긴다.
- 반례: 핵심 정세 삭제, 숫자/시점 오류, 인과관계 과장, 가격 결측을 실제 평가 또는 명시된 결정적 테스트로 점검.
- 과거 AM 입력에 오후 자료나 현재 조회한 레이크 값을 소급해서 넣지 않는다.
- 모든 시도와 미통과 결과를 남긴다. 수정 후 재평가는 새 버전으로 기록하고 보류된 요청을 새 ID로 우회하지 않는다.

[OpenAI 평가 지침](https://developers.openai.com/api/docs/guides/evaluation-best-practices)의
대표 사례·실패 사례 구분, 구체적 기준에 따른 비교, 인간 평가와의 교정 원칙을 참고했다.
평가 호출은 기존 구독 런타임을 사용하며 유료 Evals API를 사용하지 않는다.

실행 결과는 별도 evidence와 결과 보고서에 기록한다. 다섯 거래일 관찰과 실제 Slack 발간 적격성은 별도다.
