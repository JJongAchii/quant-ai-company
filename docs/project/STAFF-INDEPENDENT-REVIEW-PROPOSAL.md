# 직원 분석·설명에 대한 독립 평가 모델 제안

기준일: 2026-09-18. 아래 API 비교는 초기 제안 이력이다. 이후 사용자는 **Claude Pro 구독의
Opus 5**를 선택하고 추가 과금 비활성화와 공식 로그인을 완료했다. 현재 선택은
[ADR-0026](../adr/0026-claude-subscription-independent-review.md)과
[구독 실행기](../claude-runtime.md)를 따른다. API 비용표는 현재 운영 청구 예측이 아니다. 실제 반영 결과는
[Claude 구독 운영 확인](CLAUDE-SUBSCRIPTION-VALIDATION.md)에 기록했다.

첫 비교 후보는 Claude Sonnet 5와 Gemini 3.8 Flash다. 기본 평가자로 Sonnet 5를 우선 제안한다.
11명 규모에서는 예상 절대 비용이 작고 하나의 제공자로 운영을 시작할 수 있다. 이것은 현재 가격과
일반적인 기능을 바탕으로 한 도입 판단이며, 우리 직원 답안에서 채점 정확도 우열을 측정한 결과는 아니다.

## 비용 가정

평가 1회에 청구 입력 8,000 토큰, 청구 출력 2,000 토큰(추론 토큰 포함)을 가정한다.
원문 발췌·답변·루브릭이 입력에 모두 포함된다. 표는 표준 API 요금이며 세금·환전·검색 도구·재시도·
추가 검토를 제외한다. 공급자마다 토큰 분할과 추론량이 다르므로 같은 텍스트의 실제 비용은 달라진다.
평가 1회가 여러 호출을 쓰거나 출력이 더 길면 아래 비용을 초과한다.

| 후보 | 입력/출력 100만 토큰당 USD | 월 60회 | 월 330회 |
|---|---:|---:|---:|
| Claude Sonnet 5 | $2 / $10 | $2.16 | $11.88 |
| Gemini 3.8 Flash | $0.75 / $3.75 | $0.81 | $4.46 |
| Claude Opus 5 | $5 / $25 | $5.40 | $29.70 |

산식: 횟수 × (8,000 × 입력 단가 + 2,000 × 출력 단가) / 1,000,000.
60회는 현재 하루 총 2개 과제 × 30일, 330회는 향후 11명 각 1회/일 × 30일인 별도 가정이다.
현재 예약을 11명 매일로 변경하지 않았다. Gemini의 표준 단가는 2026-12-31까지이며 문서상
2027-01-01부터 입력 $1.50 / 출력 $7.50다. 해당 시점에는 같은 가정의 비용이 두 배가 된다.

## 연결 전에 확인할 것

1. 실제 회사 업무에서 원문·계산·사람 검토로 맞고 틀림이 확인된 답안을 모은다. 정상 답안과
   그럴듯한 오답을 포함하고, 직원과 평가자에게 정답 판정은 숨긴다. 합성 정답을 전문가 판단으로 오인하지 않는다.
2. 30~50개 검토 사례를 예비 비교에 사용할 수 있으나 통계적인 우월성 표본이라고 주장하지 않는다.
   평가 기준을 조정하는 자료와 최종 비교 자료를 분리한다. 이후 실제 오류를 추가해 판단을 갱신한다.
3. 작성 모델과 기존 점수를 숨기고 같은 기준·자료로 평가한다. 사실/인용, 논리·가정, 반례,
   정보 부족 시 보류, 수치 정합성을 따로 기록한다. 중대한 오류를 평균 점수로 상쇄하지 않는다.
4. 두 후보의 오답 통과, 정상 답안 오판, 판단 불가, 지연, 실제 청구 토큰을 비교한다. 단순히
   더 엄격하거나 장황한 평가자를 우수하다고 보지 않는다. 평가 불일치는 원문/계산으로 재검토한다.
5. 초기 월 $20 한도를 제안한다. 연결 승인이 있을 때 서비스가 요청 전 최대 비용을 예약하고,
   불확실한 완료·재시도 비용도 보수적으로 처리하도록 구현한다. 이 문서는 지출 승인이 아니다.

객관적 수치/규칙 채점은 Python을 유지한다. 다른 계열 모델은 서술형 분석의 독립 검토에 쓴다.
교차 계열이라는 이유만으로 맞는 채점으로 승격하지 않는다. 독립성은 작성자 정보 차단, 검토 근거,
사전 기준과 사람/권위 있는 정답에 대한 평가자 검증을 함께 포함한다.
