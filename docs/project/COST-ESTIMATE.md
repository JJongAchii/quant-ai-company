# Quant AI Company 비용 추정

- 기준일: 2026-09-16
- 성격: 공식 단가와 가정한 업무량으로 계산한 예산. 실제 사용량 측정이나 확정 견적이 아니다.
- 범위: 10명 BOT 조직의 추가 월 운영비. 국내·글로벌·가상자산 세 연구팀을 지원하는 회사 서비스.
- 계산 입력: [COST-ASSUMPTIONS.json](COST-ASSUMPTIONS.json)
- 후속 제안: 이 문서는 별도 API 사용 비용이다. 사용자가 이미 보유한 Pro 20x를 활용할 때의 추가 운영비와 처리량 제한은 [Codex 구독 활용안](CODEX-SUBSCRIPTION.md)에 별도로 계산했다.

## 요약

가벼운 시험 운영은 월 **40~60만원**, 하루 200회 모델을 호출하는 기본 운영은 **140~180만원**,
하루 1,000회 호출하는 집중 운영은 **580~660만원** 정도다. 첫 기본 운영의 예산 제안은 월 150~200만원이다.
이는 사용 승인이 아니며, 사용자가 정한 실제 비용 한도가 생기기 전에는 유료 운영을 시작하지 않는다.

예산 환산은 **1 USD = 1,500원**으로 가정했다. 현재 환율 조회값이 아니며 부가세·해외 결제 수수료는 제외했다.
유료 금융 데이터·초기 개발 인건비·실거래 인프라·새 클라우드 GPU도 아래 합계에서 제외했다.

## 계산 가정

- 월 30일. 호출 수는 전체 조직 합계이며 직원 한 명당 수치가 아니다.
- 호출당 과금 입력 20,000토큰, 과금 출력 3,000토큰을 가정한다. 출력은 유료 추론 토큰을 포함한다.
- 도구 결과·이전 문맥·직무 지침 등 다시 읽는 내용도 입력에 포함한다.
- 모델 호출 비중: Luna 20%, Terra 35%, Sol 25%, Astra/Fable 10%, Opus 10%.
- 단순화를 위해 각 모델에 같은 평균 입력·출력량을 적용했다. 실제로는 직무별 문맥 길이와 추론량이 다르다.
- Standard 단가와 짧은 문맥을 사용한다. 캐시·Batch 할인·가입 크레딧은 반영하지 않았다.
- Slack은 실제 사용자 1명과 앱으로 설치하는 BOT 구성, Pro 월 결제 정가 $8.75를 가정한다.
- 인프라·검색 도구 비용은 아래 공식 단가를 참고한 계획 범위이며 공급자가 제시한 묶음 견적은 아니다.

이 가정의 평균 단가는 입력 $3.24/100만 토큰, 출력 $16.94/100만 토큰이다.
따라서 호출 한 번의 평균 LLM 비용은 `20,000 × 3.24 / 1,000,000 + 3,000 × 16.94 / 1,000,000 = $0.11562`다.
사람의 요청 한 건이 도구 사용·동료 협의·재검토 때문에 여러 번의 모델 호출로 이어질 수 있다.

- **standard:** 두 상시 서비스 인스턴스·관리형 DB·영속 업무·백업을 갖춘 기본 운영. 별도 연구 계산은 보유 워커를 이용한다.
- **intensive:** 더 많은 동료 협의·도구 호출·프로젝트 병렬 진행. 가상자산 고빈도 실거래 시스템 전체 비용을 의미하지 않는다.

## 아직 합계에 넣지 않은 비용

1. **유료 금융 데이터:** 국내·글로벌의 가격·공시·기초 데이터는 기존 자산부터 검토한다. 추가 라이선스는 별도다.
2. **가상자산 과거 호가 데이터:** 거래소·종목·기간·깊이에 따라 데이터 구매·직접 수집·저장 비용이 달라진다. 공급 범위를 정하기 전에 숫자를 확정하지 않는다.
3. **실거래 인프라:** 고빈도 실행 서버·연결·관찰·운영 비용은 연구 조직 운영비에 포함하지 않았다.
4. **계산:** 보유 3070을 활용한다. 로컬 전기료·기존 콜렉터 비용은 별도이며 새 클라우드 GPU 비용은 0으로 가정했다.
5. **금융 전문 자료:** 유료 교재·논문·리서치 자료의 구매·이용 권한 비용은 별도다.
6. **초기 구축:** 구현·시험·배포 인건비와 구축 중 사용한 API 비용은 정상 운영 월 비용과 구별해 기록한다.

## 운영 예산 제안

초기에는 월 150~200만원 범위에서 기본 조직을 운영하고, 호출·토큰·검색·계산 사용량을 직무별로 측정하는 안을 권한다.
어려운 금융·연구 판단에는 강한 모델을 유지하고, 라우팅·분류·짧은 정리·기계적 상태 확인의 비용을 줄인다.
예산을 줄이면 새 프로젝트의 동시 진행량과 자동 조사량부터 조절한다.

예산 경고만으로 지출이 막히는 것으로 가정하지 않는다. 새 API 호출 전 비용 예약을 확인하고,
한도에 도달하면 추가 유료 작업을 대기시킨다. 이미 진행 중인 호출과 사용량 대사의 지연에 대비한 여유분을 둔다.
