## 현재 사용 범위

- 활성 직원: 총괄·금융전략·국내연구·데이터. 글로벌·가상자산 등 나머지 직무는 정의만 있다.
- Slack 스레드별 요청, 동료 위임·회신·취합, 대화와 문서 저장, 업무 현황 조회.
- 메시지에 제공한 내용과 모델의 기존 지식을 바탕으로 설명·검토·연구 계획·문서 초안 작성.
- 제한된 산술 계산과 등록·승인된 출처 검색. 선정 공식자료의 후보 검색·실제 HTML 원문 읽기와
  출처·조회 시각 보존을 추가했다. 광범위한 금융 지식 저장소·전문성 시험은 미완료다.
- 데이터 담당의 S3 읽기 도구: 기존 수집 EC2가 발행한 데이터 목록·날짜 범위·스키마·소량 샘플.
  조회 결과는 실제 출처로 프로젝트에 저장한다. 원본 갱신·전체 커버리지 검사·연구 실행은 포함하지
  않는다. 실측 증거와 Slack 인수 상태는 `DATA-CONNECTION-VALIDATION.json`에 기록한다.
  실제 사용자 요청의 재조회·직원 산출물·최종 Slack 답변을 확인했다. 첫 시도의 출처 ID 누락은
  짧은 ID와 충돌 검사로 수리했으며, 일반적인 오류 자동 수리 기능을 구현한 것은 아니다.
- 실행 서비스가 새 요청에 직원별 모델·활성 여부·도구·한도를 전달한다. 이미 저장된 과거 요청은
  재시도 식별자를 보존하기 위해 바꾸지 않는다.
- 범용 웹 검색·원문 수집은 별도 구현 브랜치에서 실제 구독으로 검증했다. 운영 반영은
  `WEB-ENGINEERING-VALIDATION.md`를 따른다. 3070의 승인된 고정 P11 재현은 연결됐다.
  일반 직원의 자유로운 저장소 수정·학습·거래는 제공하지 않으며 새 자율 연구는 위 검토 단위다.
  서비스 수정은 아래 개선 담당의 제한된 PR 경로로 처리한다.
- AWS 단일 서버의 재부팅 복구·S3 복원을 검사했다. Slack·업무 실행·DB·Codex 인증은
  서버에 있어 맥북 종료와 무관하게 동작한다. 장시간 부하는 계속 관찰한다.

## 직원 전문성·지속 평가 — 2026-09-17 우선 구축

사용자의 최신 우선순위에 따라 첫 연구 실행 연결보다 직원 전문 절차·평가·개선을 먼저 구축했다.
전용 절차 11개, 금융/표본 품질 도구, 영속적인 정기 평가와 실패 피드백, 개선 BOT 접수 및
현황 조회가 구현됐다. 기본 일정은 KST 03시 이후 하루 2개 과제, 최대 3개 호출/과제다.
직무별 원래 모델과 활성 직원 4명은 유지하며 비활성 직무도 격리된 교육에 참여할 수 있다.

[실제 모델·운영 인수](STAFF-DEVELOPMENT-VALIDATION.md)와 [사용 방법](../staff-development.md)을 따른다.
합성 시험 통과는 종합 전문성 인증·실제 연구 수행·고빈도 실행 능력의 검증을 대체하지 않는다.
새 문제은행은 알려진 유형의 새로운 사례이며, 실제 업무와 전문가가 검토한 새 유형을 계속 추가해야 한다.

지속형 연구 단계에도 직무별 전문 절차와 실제 모델·effort에 귀속된 평가 피드백을 제공한다.
반복된 실행·계약 오류는 기존 개선 BOT 관찰 경로에 연결한다. 수익률이 낮다는 이유만으로
직원 오답이나 시스템 고장으로 분류하지 않는다.
다음은 이 구조를 승인된 실제 다중 라운드 연구에서 검증하는 것이다.
기존 KRX 데이터 계약과 연구 규약을 재사용하고, 신규 서버·모델 교체를 먼저 전제하지 않는다.

   보고한다. 5090·맥북으로 자동 전환하지 않는다. 연구 실행 범위는 별도 연구 승인을 따른다.
4. **전문성 검증과 확장**: 금융전략 직무 시험과 실제 연구 오류 기록을 바탕으로 지식·도구·모델

   프롬프트만으로 전문성·공개 시스템 대비 우월성을 주장하지 않는다.

고정해 Codex 작성·검토와 다른 구독 모델의 비식별 내용 평가를 실행했다. 검토에서 발견한 누락과
오류, 수정에 사용한 사례와 남은 한계는 위 결과 보고서에 기록한다. 같은 사례로 수정한 개발 결과는
새로운 날의 검증이나 전문가 인증으로 세지 않는다.

9월 23일 다른 거래일 재시험에서는 저녁판의 같은 원문 보완본이 동일 모델의 내용 검토를
통과했지만, 아침판은 최종 규칙의 한 차례 보완 뒤에도 기업대출 부담의 상쇄 근거 누락과 반복
표현 때문에 실패했다. [평가 기록](BRIEFING-HELDOUT-VALIDATION.md)과 새 날짜 검증을 먼저
마친 뒤 5거래일 정시 미리보기로 넘어간다. 자동 게시 설정은 계속 꺼둔다.

9월 28일 후속: 다른 날짜의 원문을 고정해 실제 모델로 평가했다. 본문에 경제적 영향과 다른
가능성을 한 번씩 표시하고 반복을 줄였다. 숫자의 정확한 번역·한국어 금액 공백·하락률 표현을
오류로 제거하던 검증기를 고쳤다. 저녁판은 자사주 매입·업종 수급 누락을 한 차례 보완한 뒤
열두 내용 항목을 통과했다. 아침판은 내용 관련 열 항목은 통과했지만 휴장 정보의 검토 오류로
전체 판정은 보류였고, 이를 고친 최신 지침의 아침 재검토와 독립 평가 통과는 없다.
최종 관련 검사 115개가 통과했다. 새 4GB Lightsail에서 검토를 이어갔으나 일반 worker에는
브리핑 기능이 아직 배포되지 않았다. [현재 결과와 구체적인 운영 전환 순서](BRIEFING-QUALITY-20260928.md)에
새 아침판 확인, 최신 배포본 통합, 실제 핵심 종가 확인, 게시를 끈 5거래일 미리보기와 실제 Slack
인수를 남겼다. 과거 자료 평가를 정시 관찰이나 전문가 인증으로 세지 않는다.

9월 29일 후속: 정기 브리핑의 원문 공급자는 Reporter와 직접 수집기다.
확인된 병목은 최종 자료 선정, 저장 원문의 재절단, 사실별 누락 전달과 모델 입력
중복이었다. 자료 선정 단계·원문 전달 복구·미선택 후보 검토·누락 원문 보완을 구현하고 최신 main과
통합했다. [새 평가와 운영 잔여 조건](ANALYST-PIPELINE-20260929.md)을 현재 상태로 사용한다.

9월 29일 추가: [Analyst 내용 보완과 실제 평가](ANALYST-QUALITY-CONTINUATION-20260929.md)에서
과거 원문 개발판을 다시 검토한 결과 최종 12개 기준 중 6개 통과로 발간 보류됐다. 원문 수치의
확실한 WTI 만기 오류를 차단하고 다음 7일 일정·음수 표기·예상과 실현을 보강했지만,
한국 주식 방향·미국 시장 참여 범위·반대 근거의 본문 누락이 남았다. 이 실패를 반영한 새 자료
선정·작성 지침은 아직 새 날짜 실제 모델로 검증되지 않았다. 공식 BLS 달력 경로는 설치된
worker에서도 HTTP 403이며, 보호 파일 변경이 있는 현재 브랜치는 유지보수 배포 정책을
통과하지 못했다. 발송은 계속 꺼둔다.

추가 거래일 평가에서는 9월 24일 저녁이 추석 휴장으로 평가 불가임을 바로잡았다. 9월 23일
저녁의 마감 전 원문 199건과 실제 모델 선정 16건을 고정했으나, 작성 중 서버 상태 백업이
worker를 정지시켜 응답 완료 여부가 불확실하다. 같은 요청 ID의 재조회도 `uncertain`을
반환해 이 판에는 내용 판정이 없다. 영문 `KOSPI/KOSDAQ` 제목의 낮은 우선순위와 중복
마감 기사 선정은 수정했고, 이 수정의 실제 모델 품질 효과는 검증 전이다.

별도로 고정한 9월 22일 저녁판은 실제 자료 선정·작성·독립 검토 결과 12개 중 8개 내용
항목만 통과했다. 본문의 미국 AI 촉매·규모, 실제 상쇄 근거, 기업·정책 결정 조건이 부족해
발간을 보류했다. 긴 원문 인용의 마지막 문장부호 오차를 제한적으로 복구하고, 검토자의
누락 원문 요청량을 제한하며, 이슈별 다음 확인 조건을 본문에 노출하도록 구현했다.
마지막 배치 변경의 실제 모델 평가는 아직 없고, 서버의 보호 파일 릴리스 정책도 미통과다.
[증거와 잔여 조건](ANALYST-QUALITY-CONTINUATION-20260929.md)을 따른다.
