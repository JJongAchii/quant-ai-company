## 수정한 동작

- 각 이슈의 경제적 영향과 다른 가능성·상쇄 조건을 같은 본문 문단에 표시한다. 기존에는 다른 설명을
  작성해도 스레드에만 들어갔다. 실제로 관측된 상쇄 요인은 사실로도 설명하도록 한다.
- 요약은 결론, 시장 흐름은 시장 간 연결, 개별 이슈는 사건·규모·배경을 맡는다. 이미 다룬 설명을
  시장 내부 항목에서 반복하지 않고, 자료 불일치는 독자가 이해할 수 있는 말로 설명한다.
- 검토자는 실제 본문을 읽고 판단한다. 본문에 있는 반대 근거를 다른 칸에도 반복해야 통과하는
  불필요한 요구를 제거했다. 새로운 정보가 없는 반복과 내부 데이터 용어는 가독성 실패 사유다.
- 오프라인 보완 요청도 운영 서비스와 같이 기계 검증을 통과한 초안에서 만든다. 기계·내용 검토의
  거절 기록을 함께 보존한다. 새 초안의 검토 입력에서는 이전 초안과 검토 의견을 제거한다.

포맷 7, 입력 선택 3, 수치·인용 검증 4로 첫 평가를 시작했다. 새 원문을 읽기 전의
[정책·파일 해시·평가 기준](evidence/briefing-quality-20260928/evaluation-policy.json)을 보존했다.
기존 실패 사례를 새 포맷으로 렌더링하면 다섯 이슈의 대안 설명이 모두 본문에 남는다.

옛 초안의 내용 검토 통과를 의미하지 않는다.

## 결과

첫 아침 초안은 512.7초에 생성됐다. 기존 숫자 검증기는 정확한 번역 세 건을 잘못 거절했다.
`quarter percentage point → 0.25%포인트`, `Oct. 27-28 → 10월 27~28일`,
`a fifth → 5분의 1`을 인식하지 못해 금리·유가 이슈 전체가 본문에서 제거됐다.
이는 모델이 수치를 지어낸 오류와 구별한다.

그 상태의 별도 검토는 115.0초였고, 가독성은 통과했지만 중요도·반대 근거·범위·깊이는 실패했다.
검증기로 제거된 내용 외에도 주간 유가 하락폭, AI가 불리하게 작용한 업종, 통신망 투자와
천연가스 조달 목표의 누락을 지적했다.
[최초 검토](evidence/briefing-quality-20260928/am-initial-review-v4.json)를 보존했다.

정확한 분수와 월 표기를 처리하도록 검증 5로 기술 수리했다. 숫자가 다르면 거절하고 분기 실적·
서수는 비율로 변환하지 않는 반례를 포함했다. 작성·검토 지침과 선택 원문은 바꾸지 않았다.
[수리 후 정책](evidence/briefing-quality-20260928/evaluation-policy-v5.json)에 변경 이유와 해시를
기록했다. 같은 아침 원문에서 한 차례 전체 보완과 새 최종검토를 수행했다. 이 보완 입력은
[검증 버전을 넘긴 개발 과정](evidence/briefing-quality-20260928/am-repair-input-v5/context-transition.json)이며,
운영 워크플로를 처음부터 그대로 재생한 결과나 깨끗한 미사용 사례 통과로 세지 않는다.

한 차례 보완은 469.8초, 최종검토는 89.7초였다. 기계 검증 거절은 없어졌고 사실·반대 근거·범위·
깊이 등은 통과했지만, 여섯 이슈 모두 해석 끝과 대안 문장이 같은 내용을 반복해 가독성과
중요도·선별성이 실패했다. 검토자는 중복을 줄이려고 대안 ID를 거절했고, 서비스는 해당 이슈 전체를
제거했다. [포맷 7 최종 실패](evidence/briefing-quality-20260928/am-final-format7/assessment.json)를
보존하며 이 네 번 호출의 시험은 실패로 종료했다.

포맷 8은 경제적 전달 경로와 대안 설명을 본문에 각각 한 번 배치하고 부연 적용 해석은 스레드에
둔다. 검토 지침도 배치·중복 문제를 사실 오류처럼 항목 거절에 사용하지 않도록 명확히 했다.
아침 한국 휴장 표시도 추가했다. [포맷 8 정책](evidence/briefing-quality-20260928/evaluation-policy-format8.json)을

반복 생성하지 않는다. 이는 별도의 개발 검증이며 최초 시험의 실패나 호출 비용을 지우지 않는다.

범위·깊이·가독성 **열 항목은 통과**했다. 다만 검토자는 `한국 정규장: 휴장` 표시의 근거가 없다는

여전히 보류다. 휴장 표시는 모델이 생성한 뉴스가 아니라 서비스의 `edition.kr_session=null`에 따른
것이며, [캘린더 재현](evidence/briefing-quality-20260928/calendar-consistency.json)에서도 동일한 판이
나왔다. 검토 지침에 이 계약을 명시했다. 다만 변경 뒤 같은 아침판의 Codex 검토를 더 반복하지
않았으므로 최종 정책의 열두 항목 통과로 세지 않는다. 읽을 수 있는
[아침 시안](evidence/briefing-quality-20260928/am-preview.md)은 승인본이 아니다.

작성자와 기존 점수를 가린 별도 Claude 구독 모델 검토는 11.2초 후 `uncertain`이었다.
[기존 응답](evidence/briefing-quality-20260928/am-independent-receipt.json)과 새 인스턴스로 이전된
동일 요청의 `failed/uncertain` 영수증을 대조했다. 결과는 확정되지 않았고 새 요청으로 다시
실행하지 않았다. 새 컨테이너의 OOM 카운터가 0인 것은 이전 인스턴스에서 실패한 원인을 증명하지 않는다.

저녁 첫 작성은 435.7초였다. 공백이 포함된 한국어 금액 `1조 2천827억 원`과
`1조2,827억원`을 다르게 읽어 수급 반대 근거를 제거한 기계 검증 오류를 발견했다. 검증 6은
숫자·단위를 바꾸지 않고 금액 내부 공백을 처리하며, 서로 다른 금액과 뺄셈은 합치지 않는다.
[검증 6 정책](evidence/briefing-quality-20260928/evaluation-policy-final.json)과 같은 실제 작성 응답을
다시 대조해 기계 거절이 없어졌다. 작성·검토·원문 내용을 변경해 숫자를 맞춘 것이 아니다.

이전 인스턴스 전환 중 저녁 첫 검토 연결은 SSH 접속 전에 실패했다.
[미제출 확인](evidence/briefing-quality-20260928/pm-review-transport-reconciliation.json) 후,
새 인스턴스에서 검증 6의 초안에 대한 첫 검토를 실행했다. 이 검토는 112.6초에 정상 완료됐다.
[첫 판정](evidence/briefing-quality-20260928/pm-first-reviewed/assessment.json)은 사실·수치·시점·인과·
가독성 등을 통과했지만 범위와 깊이는 실패했다. 실제 진행 중인 양사의 자사주 매입과 전기·전자
업종 기타법인 순매수 1조6,224억원을 명시하지 않아, 업황 기대와 기업 관련 매수의 영향을 나누어
이해할 근거가 부족했다. 사실이 맞는 항목을 삭제하지 않고 한 차례 전체 보완을 요청했다.

저녁 보완은 459.1초에 완료됐다. 누락된 실제 자사주 매입과 업종 수급을 반영했고, 기타법인의
모든 매수가 두 회사의 자사주 매입이라고 단정하지 않았다. 다만 기계 검증 6은 원문의
`-5.66%`, `-3.22%`와 보완본의 `5.66%, … 3.22% 하락했습니다`를 다르게 읽어 시장 개요를
제거했다. [오거절 당시 판정](evidence/briefing-quality-20260928/pm-revised/assessment.json)을
보존했다. 검증 7은 명시적 한국어 하락률과 공동 서술어가 붙은 나열에 한해 음의 변동률·% 단위를
대조한다. 회귀 시험에서는 다른 수치·상승 표현·`하락하지 않았습니다`·%포인트 변경을 거절했다. 개별 숫자의 절댓값을
무조건 인정하는 방식은 사용하지 않았다. [정책 변경](evidence/briefing-quality-20260928/evaluation-policy-v7.json)과
동일 응답의 [재현](evidence/briefing-quality-20260928/pm-revised-v7/assessment.json)에 기계 거절 없음이
기록됐다. 작성·검토 지침, 원문, 모델 출력은 그대로 유지했다.

마지막 검토는 94.2초에 완료돼 [열두 항목 모두 통과](evidence/briefing-quality-20260928/pm-final-v7/assessment.json)했다.
검토자는 빠졌던 자사주 매입과 업종 수급이 본문에 반영됐음을 확인했고, 원문 16건 모두에 대해
반영 항목 또는 제외 이유를 남겼다. 최종 본문은 링크 포함 4,820자, 상세 스레드는 3,166자다.
한국장·업종 수급, 유가와 협상 조건, 국내외 금리, 미중 AI·칩 정책, 한국 자원안보 계획을 다섯
이슈로 설명한다. 원문에 없는 발표 시각과 가격 목표는 채우지 않았다. 검토의 `publish`는
이 오프라인 사례의 내용 판정이며 실제 Slack 발송이나 운영 자격 승인을 뜻하지 않는다.

## 실행 시간과 검증

아침 최초 네 호출은 합계 1,187.206초(약 19분 47초), 포맷 8 추가 검토까지의 Codex 합계는
1,316.796초(약 21분 57초)였다. 이는 실패를 포함한 이번 개발 평가의 사용 시간이다. 운영에서
다섯 번 호출한다는 뜻이 아니며, 보완을 포함한 운영 한도는 네 번이다. 표준 작성·검토 구간은
자료 마감부터 예정 발간까지 20분, 최대 허용 지연을 포함하면 30분이다. 이 합계에는 수집·큐 대기·
작업자의 중간 점검·서버 전환·Slack 전달 시간이 없으므로 정시 발간 증거가 아니다.
저녁판 네 호출은 435.706 + 112.603 + 459.132 + 94.198 = **1,101.639초(약 18분 22초)**였다.
이 역시 실제 정시 도착 여부와 구별한다.

[최종 검사 기록](evidence/briefing-quality-20260928/validation-v7.json): 최종 포맷 8·검증 7의

## 정시 미리보기 조건

이번 과거 입력 평가는 실제 정시 관찰 기간에 포함하지 않는다. 현재 정책으로 실제 원문·데이터를
수집하고, 최근 완료 한국 5거래일의 아침·저녁 발간 10개가 `briefing qualify`를 통과해야 한다.
최대 10분 지연, 원문·렌더링 재현, 수집/복수출처의 핵심 지수, 실제 작성·검토 영수증과 내용 통과가
필요하다. 보완을 사용했다면 보완·최종검토 영수증도 필요하다.

현재 과거 사례의 핵심 지수는 단일 매체를 인용한 수준이다. 당시 레이크 스냅샷을 확보하지 못했고,
복수 출처 확인이 붙은 핵심 관측으로도 저장되지 않았다. 따라서 내용 검토에 통과하는 사례라도
이 결과만으로 정시 미리보기 자격을 충족하지 않는다. 최신 정책의 새로운 아침판 내용 검토,
실제 수집값/독립 원문 확인, 실시간 실행 지연을 다음 관찰에서 함께 확인해야 한다.

미리보기 중 `BRIEFING_PUBLISH_ENABLED=false`를 유지한다. 본문 구성·내용을 검토하고 실제 Slack
앱 전달을 별도로 인수한 뒤 게시를 켠다. 이번 작업에서 서버 설정이나 발송 권한을 바꾸지 않았다.

실제 미리보기로 넘어갈 실행 순서는 다음과 같다.

1. 최신 회사 배포본과 이 기능을 통합한 릴리스를 검증하고, 새 서버에 패키지·마이그레이션·
   전용 데이터 queue를 반영한다. 모델 검토 성공만으로 이 단계가 완료됐다고 간주하지 않는다.
2. `daily_brief`의 실제 채널·소유자·Analyst 앱 연결을 설정한다. 기존 구독 인증과 비밀 저장소를
   유지하고, 게시를 끈 채 `briefing probe` 및 `briefing data-probe`로 원문·핵심 종가를 확인한다.
3. `BRIEFING_ENABLED=true`, `BRIEFING_PUBLISH_ENABLED=false`로 예정 시각의 판을 기록한다.
   실제 작성·검토·필요시 한 차례 보완을 거친다. 아침 최신 지침과 출처 확인을 포함한 내용,
   예정·확정 시각, 결측·단일 출처·축약 이유를 매 판 확인한다.
4. 현 정책으로 최근 완료 한국 5거래일의 10개 판이 쌓인 뒤 `briefing qualify`를 실행한다.
   10분 초과 지연·내용 미통과·정책 변경·불명확 호출은 해당 판을 통과로 세지 않는다.
5. 위 조건과 사람의 실제 시안 검토를 만족한 뒤 전용 앱의 본문·스레드 전달, 봇 에코 무시,
   질문 연결과 영수증을 실제 Slack에서 인수한다. 이후부터 자동 게시를 켜며 과거 판은 소급 발송하지 않는다.
