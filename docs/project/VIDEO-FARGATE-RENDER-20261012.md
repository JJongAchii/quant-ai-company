## 구조

```
Lightsail(상시): DB · Slack · 브리핑 · video-worker · Claude 실행기
  1) 입력(대본·음성·이미지)을 S3 render/<job>/<key>/in/에 업로드 (같은 키는 한 번만)
  2) 시도 기록을 먼저 저장 → RunTask (1·2번째 FARGATE_SPOT, 마지막 FARGATE)
ECS Fargate(렌더할 때만): Whisper 정렬 → 화면 검사·검수 프레임 → 장면 조각 렌더 → 합성·품질 검사
  끝난 조각은 15초마다, 회수 신호(SIGTERM) 때 즉시 S3 out/에 저장 → 다음 태스크가 이어서 렌더
  manifest.json을 마지막에 올림 = 완료
worker: 상태만 묻다가 끝나면 파일 다운로드 → 체크섬 검증 → Claude 화면 검수 → 스레드 전달
3번 실패하면 서버에서 렌더(영상은 항상 만들어진다)
```

- 보안: 태스크는 S3 `render/*` 읽기·쓰기와 `models/*` 읽기만 할 수 있다. DB·Slack·Runway·Claude 인증은 없다.
  worker 키는 서버 secret(root:10001, 0440)으로 video-worker에만 mount했고 출력하지 않았다.
- 비용 안전장치: 태스크 90분 자동 종료, worker 100분 뒤 강제 종료, `render/` 3일 자동 삭제, 로그 7일,
  ECS+ECR 예산 $20/월 알림(기존 계정 예산 알림 수신자와 같음).
- 예상 비용: 5분 영상 1편 약 280초 과금 → 온디맨드 $0.07, Spot은 그보다 낮다. 하루 2편이면 월 약 $2~5.

- 운영 회차로는 아직 돌지 않았다. 첫 운영 렌더는 오늘(10-12) 오후판 영상이다(서버에서 오후판 영상을 만드는 것도 처음).
