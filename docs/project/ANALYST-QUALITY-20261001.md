# Analyst 브리핑 품질 개선과 서버 미리보기

승인한 **발송 없는 미리보기**를 실제 서버에 설치했다. 설치 커밋은 `289dc70c6858ea229476216d7ea4c1c10ece68ff`이며
형식 15·검증 50이다. Analyst와 수집 데이터 조회 워커, 브리핑 실행 슬롯을 구성했다.
자동 발송은 꺼져 있다. 새 방식의 내용 통과와 정시 운영 검증은 아직 완료되지 않았다.

## 내용을 보완한 원인과 변경

이전 초안은 짧아서만 부실한 것이 아니었다. 중요한 규모·기존 조건·실행 시점과
상쇄 요인이 빠졌고, 수정 후에도 관련 근거가 요약의 다른 위치에 흩어졌다.
실제 원문 전체와 본문을 대조해 이를 확인했다.

- 자료 선정은 기사 앞부분뿐 아니라 조건·반대 문장·후반의 실질 내용을 읽는다.
  중복 해설보다 실제 실적·가이던스·전체 시장과 지역 자료를 우선 확인한다.
- 작성·수정은 보충 기사 전체를 다시 분석한다. 실적 구성과 규모, 증설·생산·경쟁사
  공급의 시점, 전체 수출과 품목 집중, 투자 대상의 실제 역량을 빠뜨리지 않도록 했다.
- 중요한 맥락은 **해당 이슈 바로 아래**에 자체 출처가 있는 짧은 문단으로 담는다.
  전체 4개·이슈당 2개·문단당 300자까지이며 출처·숫자·본문 크기와 최종 심사를 받는다.
- 원문 인용은 해시·정확한 위치에 연결된 참조로 전달하고 원래 문장으로 복원한다.
  최종 검토에는 모든 선택 원문과 후보 목록을 보존한다. 문맥 한도 때문에 원문을
  잘라 심사하는 대신 중복 표기만 줄였다. 숫자·단위·날짜·출처 검사는 유지했다.

읽는 흐름은 핵심 결론 → 시장 전체 흐름과 주요 숫자 → 중요한 이야기 → 다음 확인
조건이다. 변화·중요성·영향·반대 근거를 각 이야기 안에서 연결한다. 필수 배경을
상세 스레드로 숨기지 않는다. 수집 데이터는 수치·배경을, 실제 등록·검색 원문은
정책·기업·정세의 맥락을 담당하며 발표 시각과 마감 시점을 구분한다.

## 실제 내용 평가 결과

10월 2일 오전 자료의 늦은 오프라인 평가에서 첫 검토와 수정 후 최종 검토는 모두
**8/12**였다. 숫자·출처·시점·인과성·전달 경로·대안 설명·확인 조건·가독성은 통과했지만
**중요성·반대 근거·시장 범위·분석 깊이**는 미통과했다. 완전한 원문 20개·36,435자를
대조했고 기계적으로 거부된 숫자·인용 항목은 0개였다. 기술 오류 해소가 내용 통과를
뜻하지 않는다는 결과다.

수정 초안은 7,532자였다. 최종 검토가 미통과한 뒤 실제 발간 결과는 보류 안내이며,
그 긴 초안을 통과한 발간본으로 표시하지 않았다. 자료 선정·작성·검토·수정·최종 검토
총 5개 완료 호출로 사례를 종료했고 더 호출하거나 과거 결과를 바꾸지 않는다.
검증 50은 이 실패에서 확인한 원인을 보완한 다음 작성 방식이다. 새 방식의 실모델
통과 여부는 아직 확인되지 않았다.

[원래 고정 결과](evidence/briefing-analyst-quality-20261001/late-am-20261002-v47/frozen-case-outcome.json)와
[최종 개발 평가](evidence/briefing-analyst-quality-20261001/late-am-20261002-v47/development-v49/frozen-case-outcome.json)를
보존했다. 전체 원문·요청·응답·미통과 초안은 공개 Git에 올리지 않고 로컬 증거에 남긴다.
이 사례는 정시 실행·최근 5거래일 인수·전문가 인증·Slack 전달의 증거가 아니다.

## 실제 서버에서 확인한 범위

설치 시각은 **10월 2일 12:35 KST**다. 승인 ID는
`chat-analyst-preview-approved-20261002`이며 보호된 자동 릴리스 정책은 바꾸지 않았다.
소유자가 승인한 수동 설치 경로에서 산출물 해시·기존 설정·진행 중인 외부 효과를
검사하고 전용 백업을 남긴 뒤 필요한 워커만 교체했다.

- 새 이미지에서 실제 로드되는 회사 소스와 잠긴 의존성, qdata 코드 버전을 검증했다.
  기존 이미지의 오래된 `PYTHONPATH`가 새 설치를 가리는 문제를 고쳤다.
- 기존 직원·허용 채널·인증·요청 영수증과 다른 서비스 컨테이너를 보존했다.
  기본 모델 인증·계정·작업 볼륨도 유지했다. 불확실한 옛 요청은 재실행하지 않았다.
- 조회 워커의 192MB 제한에서는 실제 검사 중 종료·재시작이 발생했다. 동일 워커를
  384MB로 보정했고 이제 Compose 재생성에도 유지된다. 현재 재시작·OOM 표시는 없다.
- 실제 qdata API 조회는 `4`개 데이터셋에서 성공했다.
  현재 관측 `0`개와 날짜가 표시된 배경
  `16`개를 구분했다. 장 마감 전 검사이므로 당일 한국 종가의
  완전한 커버리지나 최종 브리핑 통과를 뜻하지 않는다. 결측·오래된 관측은 진단으로 남긴다.
- 실제 Temporal의 수집·분석·데이터 워크플로를 조회해 실행 상태와 이력을 확인했다.
  개별 예정 발간본의 완료·정시 작성 여부는 별도 검증한다. 설치 중 모델·Slack 호출은 없다.

[실제 설치·조회 영수증](evidence/briefing-analyst-quality-20261001/preview-installation-v50.json)에
확인 범위와 해시를 기록했다. 기존 일반 워커·Slack 소켓은 보존했으므로 후속 대화의
실제 전달은 아직 운영 인수되지 않았다.

## 기술 검증과 다음 정기 실행

검증 50의 관련 테스트 **283개**가 실제 PostgreSQL·로컬 Temporal을 포함해 통과했다.
배포 보정 테스트 **5개**도 통과했다. 이 테스트의 모델·Slack은 모의이며
실모델 내용 검토나 실제 Slack 전달과 구분한다.
검증 50, 소스 경로 보정, 조회 메모리 보정의 GitHub CI도 모두 성공했다.
[CI50](https://github.com/JJongAchii/quant-ai-company/actions/runs/36952396557),
[런타임 CI](https://github.com/JJongAchii/quant-ai-company/actions/runs/36955322244),
[메모리 CI](https://github.com/JJongAchii/quant-ai-company/actions/runs/36958320184).

10월 2일 오후의 [검증 정책](evidence/briefing-analyst-quality-20261001/prospective-pm-20261002-v50-operating-policy.json)은
제목·원문과 수집 마감 전에 고정했다. **19:10 KST 수집 시작 → 19:30 마감 → 20:15 완성 목표**다.
마감 전의 실제 저장 원문과 수집 관측으로 작성한다. 자료 보충 검색 최대 1회와
자료 선정·작성·검토·수정·최종 검토 최대 5회, 합계 최대 6회다. 원래 정책의 5회 표기와
운영의 선택적 검색 1회를 수집 시작·제목 확인 전에 일치시켰으며 원래 정책과 해시를
보존했다. 수정은 한 번이고 12개 기준 및 원문·본문 비교를 확인한다. 기존 실패 사례의
5회 한도와 결과는 바꾸지 않았다. 정책 고정 시점과 설치 시점에는 아직
수집 시작 전이므로 예정 발간본이 등록·완료됐다고 표시하지 않았다.

자동 발송에는 새 본문의 내용 통과, 정시 미리보기와 최근 5거래일 운영 검증, 실제 채널·
전달 영수증 및 사람의 내용 확인이 남아 있다. 이번 승인은 미리보기 설치이며 발송 승인이
아니다. [현재 요약](evidence/briefing-analyst-quality-20261001/quality-summary.json)에 남은 범위를 명시했다.
