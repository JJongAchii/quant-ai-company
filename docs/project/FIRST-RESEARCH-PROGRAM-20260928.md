# 첫 자료 기반 연구 프로그램 준비안

상태: **검토안, 미승인, 필수 입력 미확정**. 아래 값은 예산 제안이며 실행 권한이 아니다.
자료를 고르기 전에 결과나 재현 목표값을 만들어 넣지 않는다.

## 제안하는 운영 한도

| 항목 | 검토안 |
|---|---|
| 시장 | 국내 ETF, 국내 개별 주식 |
| 방식 | 원문 재현, 검증 가능한 주장, 전략 개선; 원문 조건 불일치 시 시장 전이로 명시 |
| 누적 과학 시행 | 최대 24회 |
| 누적 워커 계산시간 | 최대 36,000초(10시간), 예약 포함; 실행 오버헤드 초과 시 추가 실행 중지 |
| 과제 | 최대 6개, 과제당 최대 4회, 동시 과제 1개 |
| 개별 실행 제한 | 자격검사 120초, 평가 900초 제안; 실제 자료 크기 자격검사 뒤 고정 |
| 종료 | 예산 소진, 필요한 원문/데이터 부족, 근거 있는 다음 가설 부재; 검증·보고는 마무리 |
| 공개 | 기존 연구 스레드, 별도 승인된 research-library 채널이 있으면 함께 게시 |

위 조합은 준비안이다. runtime/profile digest와 `MissionSpec.search`에 같은 값을 고정한
완전한 `ResearchProgram`이 소유자 승인을 받아야 과제를 만들 수 있다.

## 프로그램 JSON을 만들기 전에 필요한 증거

| 필수 입력 | 현재 상태 | 확인 방법 |
|---|---|---|
| 독립 검토를 통과한 원문·위치·출처 ID | 새 프로그램에 연결하지 않음 | 같은 소유자의 quant-feed 원문 또는 승인된 프로젝트 출처 |
| 주식/ETF 당시 유니버스와 정정·상장폐지·거래 가능성 | 새 입력 스냅샷 미준비 | qdata의 검증된 시점별 자료와 커버리지·가격 결손 보고서 |
| `warmup.json`, `development.json` SHA 및 lake ID | 미확정 | 준비한 불변 파일의 실제 SHA |
| 개발/봉인 기간, 신호 가용 시각, 비용·위험 제한 | 미확정 | 자료 커버리지 및 승인된 연구 정책에 대조 |
| 재현할 원문의 추정량·목표값·허용 오차 | 미확정 | 원문의 실제 방법·시장·기간·결과와 대조; 현재 상관 평가기와 불일치하면 차단 |
| 새 서버/3070 프로필 | 합성 자격검사 완료, 과학 프로필 미등록 | `quant_company.research.domestic_profile`로 실제 입력과 exact bundle을 고정 |
| 현재 회사 서버 배포본·이전본·백업과 진행 job | 활성화 직전 확인 필요 | 기존 배포 잠금·백업·release registry 절차 |

원문 재현에 필요한 데이터가 없으면 해당 과제를 `blocked`로 남기거나 소유자가 승인한
시장 전이 envelope에서 새 과제를 제안한다. 논문의 숫자 대신 임의 값을 넣거나, 최신 종목
목록을 과거 유니버스로 간주하거나, 실제 snapshot 없이 프로그램 JSON을 승인 요청하지 않는다.

등록 프로필은 총괄의 `research_control: program_catalog`에서 조회한다. 원문·데이터 준비가
완료되면 총괄이 `program_draft`로 전체 명세를 제시하고, 인증된 Slack 승인으로 시작한다.

## 인수 조건

- ETF/주식 각각 두 개 이상의 서로 다른 과학 실험과 이전 반론·부정적 결과에 따른 후속 선택.
- 원문 재현, 주장 검토, 전략 평가에서 사용한 추정량과 한계를 각각 명시.
- 실행 전 자격검사, 누적 예산 예약/정산, 실제 인과성 감사 파일과 별도 의미 검토.
- 보존된 보고서와 서버 출처 바이트 대조, 실제 구독 모델 요청 식별자와 Slack 전달 영수증.
- 재시작 후 동일 작업 복구, 불명확한 실행의 자동 재실행 금지, 예산 소진 시 새 실험 중지.

현재 구현·증거는 [검증 보고서](RESEARCH-PROGRAMS-VALIDATION-20260928.md)를 따른다.
