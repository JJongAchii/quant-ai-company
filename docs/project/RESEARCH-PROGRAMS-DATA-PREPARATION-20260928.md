# 첫 연구 프로그램의 실제 입력 준비

상태: **실제 데이터·로컬 프로필 준비, 미배포·미승인·과학 실험 0회**.
[입력 영수증](evidence/research-programs-20260928/real-inputs.json)과
[프로그램 초안](evidence/research-programs-20260928/first-program-draft.json)에 정확한 해시와 범위를 기록했다.
시장 가격이나 연구 성과 수치를 읽거나 비교하지 않았다.

## 입력 출처와 유니버스

- 기존 `s3://insight-invest-datalake/qdata/clean/`의 주식·ETF 시세와 ETF 당시 메타를
  **읽기 전용**으로 사용했다. API 코드는 배포에 고정된 quant-data
  `d6d7d0ed066ec49541e9acdd657c9ec5692ffc52`의 독립 체크아웃이다.
  S3 파일 크기·수정 시각·ETag를 조회 전후 대조하고 JSON 입력의 SHA-256을 고정했다.
- 2022-12-29까지의 마지막 20개 관측 거래일 거래대금 평균만으로 국내 ETF 10종과
  KOSPI 보통주 20종을 선정했다. ETF의 당시 레버리지·인버스 표기와 주식 보통주
  종목코드 규칙을 사용했다. 2023년 이후 생존 여부나 성과로 종목을 교체하지 않았다.
- ETF 준비 구간은 2022-08-01부터, 주식은 2022-02-01부터다. 공통 개발구간은
  2023-01-02~2025-12-30(36개월). 2026년 이후 구간은 입력 파일에 넣지 않았다.
  ETF의 이전 2022년 초 저유동성 행과 주식 한 종목의 상장 전 행은 별도 실패 영수증에
  남기고, 그 기간을 준비 구간에서 제외했다. 이는 시장 성과를 본 뒤 종목을 바꾼 것이 아니다.
- 최종 입력에는 필수 가격 결손·누락이 없다. 주식의 거래 불가 행 **194개**는
  `tradable=false`와 시가 0으로 그대로 남겼다. 해당 종목을 보유하거나 매수해야 하는
  후보는 평가기가 거절한다. 이 데이터 준비 판정은 주식 후보가 자동으로 실행 가능하다는
  판정이 아니다. 배당 포함 총수익과 상장폐지 정산을 주장하지 않는다.
- 신호용 조정 종가는 각 신호 날짜에 알려진 마지막 원종가로 종목별 재기준화한다.
  나중의 기업행동으로 과거 시계열 전체가 상수배 재조정돼도 당시 절대 가격·순위에
  그 미래 배율이 들어가지 않도록 한다. 여러 절단 시점과 종목별 재배율 테스트를 추가했다.

실제 JSON 입력은 큰 데이터 파일이므로 회사 Git에는 넣지 않았다. 준비된 경로는
이 작업공간의 `.local/science-inputs/`이며, 해시가 바뀌면 프로필 준비 단계에서 거절한다.
워커에는 별도 격리 경로로 정확히 같은 바이트와 영수증을 배치해야 한다.

## 프로그램 초안과 남은 결정

초안은 ETF/주식의 전략·예측 주장 네 envelope, 총 24회·10시간·과제 6개·동시 1개를
제안한다. 처음부터 목표값이 필요한 **원문 수치의 정확한 재현**은 해당 추정량과 실제
논문 기준값을 찾기 전까지 넣지 않았다. 자료를 읽고 방법을 다른 시장에 적용하는
연구는 `market_transfer`로 표시한다. exact replication을 주장하려면 원문과 같은
추정량·시장·데이터·기간·방법을 대조한 별도 고정 envelope가 필요하다.

프로그램 초안의 이전 연구 출처 ID는 기존 ETF 검증 문서의
`research:6a64df0e-9c60-555f-aa3a-a80a70e7f985`다. **현재 운영 프로젝트에서 이
출처가 승인 상태인지 이번 준비 과정에서는 조회하지 못했다.** 승인 버튼에 붙일 전체
명세를 제시하기 전에 서버에서 이 출처와 같은 소유자의 독립 검토 통과 원문을 확인한다.
`include_quant_feed=true`는 그 원문을 직원이 선택할 수 있게 한다.

프로필은 기존 3070 런타임의 정확한 mount digest와 새 평가 코드·입력 해시로 로컬에서
생성했다. 워커 격리 경로에서 다시 준비·검사하고 서버 컨테이너 경로로 bundle을 배치해야
실제 `program_catalog`에 등록할 수 있다. 현재 AWS Lightsail 회사 호스트는
`quant-company-host-4gb-20260928`로 관측됐다. 기존 배포 문서의 서버 용량·release를
그대로 현재 상태라고 가정하지 않는다.

운영 활성화와 실제 자료 실험은 [배포·인수 절차](../runbooks/research-programs.md)의
별도 검토 단계다. 이번 영수증은 그 결정을 대체하지 않는다.
