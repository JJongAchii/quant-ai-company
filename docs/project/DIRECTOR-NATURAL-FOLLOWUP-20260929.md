# 총괄의 자연어 진행 질문 응답 수리

2026-09-29 research-center에서 사용자가 새 연구 프로그램을 승인한 뒤 “진행중이야?”와
“그 새 연구를 진행중에 있냐고”라고 물었다. 두 메시지는 접수됐지만 분류 결과 `status`가
고정 업무 건수 목록을 생성했다. 그 목록은 새 프로그램 단계를 조회하지 않아 질문에
답하지 못했다.

새 프로그램 승인은 2026-09-29 00:21:12 UTC에 기록됐다. 01:22 UTC 읽기 전용
확인에서는 프로그램이 `active`, `program_proposal` 단계가 `researcher_kr`에서
`running`이었다. 선정된 새 과제와 자식 미션은 각각 0건이었다. 같은 프로젝트에 남은
이전 미션의 감사 대기는 별도 상태다. 승인 직후 실제 새 연구는 자료 검토와 과제 제안
단계였으며, 실험 실행 단계는 아니었다.

변경은 자연어 진행 질문을 대화 작업으로 보낸다. 분류 모델이 다시 `status`를 제안해도
명시적인 단독 상태 명령이 아니면 서버가 후속 답변 작업으로 전환한다. 총괄 답변에는
승인 시각, 프로그램 단계, 과제 상태와 자식 미션 수를 담은 서비스 기록을 제공한다.
단독 `상태` 명령은 모델 사용이 막힌 동안에도 즉시 조회되며 프로그램 단계도 표시한다.
이전 질문을 자동 재전송하지 않는다.

최종 합본의 검증은 로컬 실제 PostgreSQL에서 전체 1,279건 통과·46건 건너뜀,
변경 경로 집중 검사 28건 통과, 전체 Ruff 린트 통과다. 실제 3070의 합성 ETF
sandbox 두 단계와 결과 소비 검사도 통과했다. Slack과 모델 응답은 시험 입력으로
검증했으며 변경 후 실제 Slack 자연어 답변은 다음 사용자 메시지를 기다린다.

운영 반영은 [지속형 연구 배포·복구 절차](../runbooks/autonomous-research.md)에 따라
완료됐다. 앱·Slack 수신부·모델 worker·3070 연구 worker는
`eec5e2326dc5ecfcfe8bc7a98840afec0820242a`로 실행 중이다. 운영 DB와 Codex
runtime은 교체하지 않았다. 이전 질문은 재전송하지 않았으며, 다음 실제 Slack 질문의
문장형 답변은 별도로 확인해야 한다.
