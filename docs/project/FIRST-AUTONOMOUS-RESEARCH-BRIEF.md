## 목표와 성공 판단

기존 P11 국내 ETF 연구를 이어, 비용을 보수적으로 반영한 **절대수익 CAGR**을 개선할
피처를 찾는다. 이전 결과와 반론을 읽고 다음 가설을 선택하는 실제 직원 협업을 검증한다.
실행 순서를 미리 여섯 번 예약하지 않는다. 독립 반론에 따라 가설을 고쳐 선택한다.

연구 안에서는 gross exposure ≤ 1을 지킨 후보 중 편도 30bp 비용 후 절대수익 CAGR이
가장 높은 후보를 보존한다. 동률이면 기존 후보를 유지한다. Sharpe·낙폭·월별 수익은
원인을 설명하는 자료이며 새로운 채택 문턱으로 사용하지 않는다. 이번 탐색이 수익성 있는
후보를 보장하지 않으며, 기존 M2보다 좋아졌는지는 동일 조건의 확인된 비교 근거로만 판단한다.

개발기간은 이미 P11에서 관찰했다. 이번 결과는 개발구간 개선의 증거이며 새로운
미관측 구간 성과나 자본배치 승인이 아니다. 유효한 후보가 없다는 결론도 보존한다.

## 등록한 여섯 가설

공통 정보 창은 기존 M2와 동일하다. 최근 21개 관측 수익률을 제외한 231개를 쓰고,
각 시점의 적격 종목 안에서만 순위를 계산한다. M2는 기존 출처로 보존한다.

| 변형 | 바꾸는 것 | 직원들이 검토할 핵심 반론 |
|---|---|---|
| A25 | M1 순위 75% + 상승·하락 지속성 순위 25% | 지속성을 줄이면 원래 가설의 의미가 사라지는가 |
| A75 | M1 순위 25% + 지속성 순위 75% | 작은 일간 변동의 부호에 지나치게 민감한가 |
| B | 231개 일간 수익을 11개의 21관측 블록으로 묶은 방향 지속성 | 블록 경계의 우연에 의존하는가 |
| C | 일간 부호에 시간순 1~231 고정 가중치를 준 지속성 | 최근 정보 편중이 회전율·추격매수를 늘리는가 |
| D50 | 현재 M2와 직전 월말 당시 M2를 50:50 혼합 | 반응이 늦어지는 비용보다 교체 감소 효과가 큰가 |
| D75 | 현재 M2와 직전 월말 당시 M2를 75:25 혼합 | 완만한 평활화에도 차이가 남는가 |

B/C는 M1 순위와 새 지속성 순위를 50:50으로 섞는다. D의 이전 점수는 당시 입력과
종목 구성으로 다시 계산한다. 이전 점수가 없는 현재 적격 종목에는 현재 M2를 사용한다.
새 수식·창 길이·가중치·포트폴리오를 탐색하려면 새 명세가 필요하다.

## 반복 예산과 종료

- 이 명세 전체의 서로 다른 새 과학 실험은 **최대 6회**다. 주기당 최대 4회이며,
  2회 연속 유의미한 개선이 없으면 총괄이 검토한다. 여기서 개선폭은 CAGR 0.1%p 초과다.
- 총괄은 감사된 직전 결과를 인용해 남은 승인 가설을 계속 연구하거나 대기를 선택한다.
  주기를 다시 시작해도 누적 6회는 초기화되지 않는다. 총 범위를 소진하면 마지막 해석·감사·
  보고를 마치고 새 명세를 기다린다. 동일 설정의 이름·공백 변경은 새 실험이 아니다.
- 기술 수리는 과학 실험 수와 분리한다. 횟수 상한은 없으며 같은 실패의 그대로 재실행은
  막는다. 구독 한도·3070 오프라인은 대기하고, 실행 상태가 불명확하면 먼저 대사한다.
- 기존 P11의 과학 시행 3개와 이번 시행 이력을 함께 보존한다. 기술 수리 행 수를
  통계적 시행 수로 세거나 과거 시행을 지우지 않는다.
