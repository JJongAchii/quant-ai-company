## 과거 증거의 해석

이 디렉터리는 quant-workspace의 회사 전용 설계·운영 증거를 보존합니다. JSON에 기록된
커밋·상대 경로·digest는 원래 quant-workspace 시점의 증거이며 이 저장소의 현재 검증으로
재해석하지 않습니다. 원본은 https://github.com/JJongAchii/quant-workspace/pull/42 에 남습니다.
기존 qws INTENT/STATUS/EVENTS는 원래 계약으로 보존하며 복제하거나 덮어쓰지 않습니다.
그 계약을 읽는 것과 회사의 새 개발·검증 기록을 두 저장소에 쓰는 것은 별개입니다.
