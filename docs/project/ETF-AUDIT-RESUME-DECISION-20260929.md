## 지금의 결정

37번째 요청과 기존 미션의 연구 결과를 그대로 보존한다. `unverified` 성과를 검증된 결과로
발행하지 않으며 동일 결과를 재감사하지 않는다. 이 조사에서 새 모델 호출·백테스트·주문은
없었다. 기존 후보의 성과 수치도 보고하지 않는다.

재개 경로는 두 가지다.

- 해당 입력 범위에 연결되는 시점별 원본·수정 이력과 장전 기준가격 자료를 확보하고,
  기존 코드의 입력·체결이 당시 정보로 재현되는지 검사한다.
- 그런 자료가 없다면, 시점별 가용성이 입증되는 입력·유니버스·체결 정책으로 새 연구 범위를
  등록한다. 원래 2014~2026 성과를 소급 승인하지 않고, 실제 데이터 자격검사와 인과성 가드를
  통과한 **새 trial**만 평가한다. 분배금·조정가격의 경제적 의미도 새 정책에 명시한다.

실험에는 개발 구간, 경제 목적·기준선, 비용·위험 조건, 허용 변경 범위와 실행 예산을 담은
