## 2. 재발 방지

- **PR #211을 현재 main 위에 다시 올렸다.** 충돌은 `video/store.py`의 `renew()` 추가 하나였다.
  - 빈 원고는 이어 고치지 않고 전체 단계 지시문으로 다시 묻는다.

  - 오늘 `-r1`처럼 개요만 채운 원고도 더는 통과하지 못한다. 빈 원고 판정도 요약·이슈 기준으로 바꿨다.
  - 재시도는 지금처럼 만료 전까지 계속한다. 끝까지 받아들일 원고가 없으면 기존 안전장치 본문이 나간다.
- **시험.**

  - `test_a_draft_with_an_overview_but_no_summary_or_issue_is_written_again_too`
