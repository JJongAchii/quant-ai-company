# data-watch 운영 게시·가독성 인수

2026-09-28 KST 기록. 이 문서는 [구현·로컬 검증](DATA-WATCH-VALIDATION.md) 이후의
실제 운영 증거를 구분해 기록한다. [기계 판독 영수증](evidence/data-watch-production-20260928.json)에
전송 ID, 배포 해시와 남은 범위를 보관한다.

## 채널 메시지의 뜻

9월 23일 점검에서 설정된 최신 레이크의 데이터셋 38개 중 Parquet 메타데이터를
37개 확인했고 `us_prices` 1개는 확인하지 못했다. 재검사 결과 `us_prices`의
Parquet footer가 qdata의 2 MiB 조회 한도를 넘는 것으로 분류됐다. 원본 파일 손상이나
데이터 지연으로 판정한 결과가 아니다. “최신성 기준 미등록 38개”는 검토된 데이터별
공표 시각·거래 달력이 없어 지연 여부를 판정하지 않았다는 뜻이다. 승인된 ETF 연구의
고정 입력 6개는 현재 레이크와 별도의 대상이며 운영 상세 검사가 아직 꺼져 있다.

처음 게시한 긴 요약은 Slack에서 2개 글(3,871자와 736자)로 나뉘어 가독성이 낮았다.
수정 후 [일일 요약](https://achiisquantresearch.slack.com/archives/C0C3Q7H30HL/p1790150394271459)은
271자짜리 한 글로 게시됐다. 전체 이름은 채널에서 `목록`, 간단한 해석은 `상태`로
조회하도록 표시한다. `us_prices`의 구체적 이유는
[기존 장애 스레드](https://achiisquantresearch.slack.com/archives/C0C3Q7H30HL/p1790150595245189)에
288자 답글로 게시됐다. 새 요약과 답글은 PostgreSQL delivered 영수증의 메시지 ID·시각이
Slack 원문과 일치했다. 과거 분할 게시물은 전송 이력을 보존하기 위해 삭제하지 않았다.

## 배포와 검증

9월 23일 `837ac72a76cf94625afa2b4ccbee5eb103ae6e03`을 운영에 배포했다.
data-watch 수집·Slack 게시는 켰고, 고정 연구 입력 상세 검사는 꺼 두었다.
전용 Maintainer와 improvements 채널은 활성화했다. 다른 비활성 직원은 일괄
활성화하지 않았다. 데이터 원본·연구 입력도 변경하지 않았다.

동일 코드에서 실제 임시 PostgreSQL·Temporal을 사용한 전체 검사는 1,158개 통과,
38개 건너뜀; 배포 계약 31개 통과; Ruff 및 GitHub CI 통과다.
9월 27일 22:41 UTC 재확인에서 운영 릴리스 경로는 같은 커밋이며
data-watch-worker를 포함한 회사 서비스와 PostgreSQL·연구 worker가 실행 중이었다.
이 재확인은 서비스 상태 확인이며 새 Slack 대화나 전체 데이터 재검사를 뜻하지 않는다.

운영 인증 API의 초기 관측은 38/37/1이었고, 실제 Slack 요약과 장애 답글의 전달
영수증을 확인했다. 소유자가 직접 `상태`/`목록`을 묻는 서명된 인바운드 대화,
improvements의 실제 신규 케이스, 승인 연구 입력 6개의 실제 검사 결과는 아직
운영 E2E로 확인하지 않았다. 종목별 거래일 누락이나 전략 성과도 이 감시 결과로
판정하지 않는다.
