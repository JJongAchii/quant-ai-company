# 서버 비용을 줄이는 첫 운영안

- 기준일: 2026-09-16. 최신 2GB 생성·검증 승인으로 AWS 배포를 완료했다.
- 요청: “서버는 비용 최소화할 수 있나?”
- **AWS default 프로필, 서울, Lightsail 2GB·월 $12**를 사용한다. 4GB는 구매하지 않았다.
- 네 직원의 합성 협업을 실행했고 약 4분간 가용 메모리 최소 1072.5 MiB, OOM kill 0을 확인했다.
  단일 모델 작업의 짧은 검사이며 장시간 부하 보장은 아니다. 1GB 이하는 검증하지 않았다.
- Socket Mode이므로 도메인이 필요 없다. AWS+S3 계획은 월 $15~18이며 Temporal 사용료는 별도다.
  아래 Hetzner·4GB 수치는 이전 비교안이다. 최신 [배포·비용 현황](AWS-DEPLOYMENT-PLAN.md)을 따른다.

## 구성 원칙과 이전 VPS 비교

**한 서버에 회사 서비스·PostgreSQL·Codex CLI 실행기를 함께 둔다.**
직원 10명의 직무·업무함·기억은 독립된 데이터로 유지한다. 모델 작업은 처음에 1개씩 실행하며
사용자 요청에 우선순위를 준다. 직원 수만큼 서버나 상주 모델 프로세스를 만들 필요는 없다.
실제 메모리·도구 실행 부하를 확인해 용량을 정한다. 아래 8GB VPS와 4GB AWS 수치는 비교 견적이다.

- 서버: Slack 수신·발신, 직원 간 메시지, 예약 업무, 업무 상태·지식, 가벼운 코드·도구 실행.
- 추론: 기존 Codex 구독의 공식 실행 어댑터. 서버 자체에 LLM을 올리는 GPU 비용은 없다.
- 영속 실행: 기존 제안의 Temporal Cloud 종량제를 유지한다. 실행 이력에는 큰 자료 대신 참조를 기록한다.
- 저장: 같은 서버의 PostgreSQL과 기존 S3/Git 산출물 경로. 별도 관리형 DB·로드밸런서는 확장 단계다.
- 복구: 서버 백업과 별도로 DB의 일관된 백업을 외부 저장소에 보관하고, 새 서버로 복원해 검증한다.
- 연구 계산: 3070이 켜져 있을 때 실행한다. 꺼져 있으면 계산을 대기시키고 회사의 접수·논의는 유지한다.
- 기존 정기 수집 EC2는 수집 전담·자체 종료를 유지한다. 상시 회사 서버와 합치지 않는다.

## 월 예산

예산 환율은 1 USD = 1,500원이며 실시간 환율이 아니다. 아래 합계는 기존 Codex 구독료·세금·
카드 수수료·유료 금융 자료·기존 수집 비용·전기료·구축 인건비·고빈도 실거래 인프라를 제외한다.

Hetzner의 2026-06-15 가격 조정표와 제품 사양을 확인했다. 공개 제품 페이지에는 CX33 등 저가형의
가용성 제한 표시가 있으므로 이 가격으로 즉시 생성할 수 있다고 확정하지 않는다. 선택 지역·계정에서
공급을 확인해야 한다. 유럽 배치는 대화·비동기 연구 업무용이며 거래소 인접 실행 환경을 대신하지 않는다.
[공식 가격](https://docs.hetzner.com/general/infrastructure-and-availability/price-adjustment/),
[사양·가용성 안내](https://www.hetzner.com/cloud/cost-optimized/),
[백업 과금](https://docs.hetzner.com/cloud/billing/faq/),
[IPv4 과금](https://docs.hetzner.com/cloud/servers/overview/).

Temporal 직접 가입 PAYG 공개 단가로 월 720시간을 가정한다. 낮은 예시는 3만 actions·평균 활성
저장 0.05GB·보관 0.5GB이고, 높은 예시는 10만 actions·평균 활성 0.1GB·보관 1GB다.
각각 `(actions / 1,000,000 × 50 + activeGB × 720 × 0.042 + retainedGB × 720 × 0.00105) × 1.1`
을 계산했다. 무료 크레딧은 합계에서 빼지 않았다. 업무량·이력 보관량이 늘면 비용도 늘어난다.
[Temporal 공식 단가](https://temporal.io/pricing).

Slack 무료 요금제도 가능하지만 앱 최대 10개·90일 메시지 조회 제한이 있다. 직원 앱 10개를 두면
추가 연동 여유가 없다. 초기 기능 검증에서는 무료를 사용할 수 있고, 10명 조직의 운영 예산에는 Pro를
포함한다. 회사의 업무·판단·지식 원본은 Slack 요금제와 관계없이 자체 DB에 보관한다.
[Slack 공식 가격](https://slack.com/intl/ko-kr/pricing).

## AWS 대안

AWS Lightsail Linux 4GB는 IPv4 포함 월 $24다. 단일 Codex 작업부터 시작하고 별도 관리형 DB는 두지 않는다.
백업·저장·도메인 충당 $3~6, Temporal 예시 $3.73~9.66, Slack Pro $8.75를 더하면 월 $39.48~48.41,
약 5.9~7.3만원이다. **월 6~8만원을 계획 예산**으로 잡는다. 8GB 인스턴스는 $44여서 같은 구성에서
월 약 3만원이 더 든다. 사양 적정성과 선택 지역의 실제 생성 가능 여부는 배포 전 확인한다.
[AWS 공식 가격](https://aws.amazon.com/lightsail/pricing/).

## 무료 서버와 가용성의 한계

Oracle Always Free는 조건 내에서 서버 임대료를 줄일 수 있지만, 공식 문서에 유휴 인스턴스 회수 조건이
있다. 첫 검증용 후보로는 가능하나 상시 사무실의 기본 호스트로 권하지 않는다.
[Oracle 공식 조건](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm).

단일 VPS는 맥북과 독립된 상시 운영을 지원하지만 서버 장애 시 복구 동안 중단된다. 외부 백업은
자동 장애 인계와 다르며, 복원 시점 이후 데이터 공백을 대사해야 한다. 저가 구성은 기존 인수 A23의
다중 인스턴스 장애 인계 목표를 충족하지 않는다. A24 백업 복원은 첫 운영부터 검증하고, A23은
이중화 확장 때 검증한다. 구독 한도·인증 갱신으로 추론이 대기하는 경우도 서버 가동과 별도로 표시한다.

처리량은 아직 측정하지 않았다. 초기에는 작은 작업공간·자료 캐시만 서버에 두며 전체 데이터 레이크나
호가 이력을 복제하지 않는다. 동시 실행·자료량·메모리·대기 시간을 관찰해 필요한 자원만 늘린다.
