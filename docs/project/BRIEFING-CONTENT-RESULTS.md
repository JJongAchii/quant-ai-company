# Analyst 브리핑 — 실제 원문·모델 내용 평가

평가일: 2026-09-22~23. 입력 자료의 기준일은 **2026-09-22**다. 현재 시황으로 재게시하지 않는다.

앞선 합성 예시는 전문가 수준의 증거가 아니었다. 이번에는 기존 회사 수집 기록에서 실제 원문을
읽고, 실제 구독 모델이 작성한 결과를 검증하면서 내용과 구현을 수정했다. 시장 전체 흐름,
중요 사건의 배경과 규모, 자산 간 관계와 반대 근거를 본문에 담도록 바꿨다.

다음은 실제 모델의 마지막 출력에 서비스 검증·렌더링을 적용한 결과다. 사람이 문장을 대신
작성하거나 실패한 출력 파일을 고쳐서 모델의 성공으로 만들지 않았다.

- [아침판 — 미국장과 한국장 확인 사항](evidence/briefing-content-20260922/am-final/brief.md)
- [저녁판 — 한국장과 주요 정세·정책·기업 이슈](evidence/briefing-content-20260922/pm-final/brief.md)
- [전체 요청·응답과 평가 집계](evidence/briefing-content-20260922/evaluation-summary.json)

## 실제 평가에서 확인한 것

| 검사 | 아침판 | 저녁판 |
|---|---|---|
| 마지막 기계 검증 | 제외 항목 없음 | 제외 항목 없음 |
| 별도 Codex 내용 검토 | 12개 항목 통과 | 조건 한 문장 수정 후 12개 항목 통과 |
| 원문별 반영/제외 검토 | 16건 전체 | 16건 전체 |
| 본문 주요 이슈 | 6건 | 6건 |
| 본문 전송 문자 수, 링크 포함 | 4,810자 | 4,887자 |
| 다른 모델의 사실·논리·가정 평가 | 세 항목 모두 supported | 세 항목 모두 supported |
| 다른 모델의 내용 한계 평가 | concern | concern |

독립 검토자는 두 판 모두 본문만으로 시장 흐름과 주요 이슈를 파악할 수 있다고 평가했지만,
추가 보강도 요구했다. 아침은 미중 AI 협의체·후속 일정, 한미일 대북 메시지, 이란 제재의 시행
시점 설명이다. 저녁은 개인 수급과 일부 연준 발언, 일정 표현의 중복이다. 이 지적을 지우거나
자동 검사 통과로 상쇄하지 않았다. 아침의 특정 출처가 본문에 안 보였다는 지적은 모든 근거
번호를 표시하도록 고쳤다. 독립 평가의 본문과 최종 본문은 출처 표시·초안 라벨을 제외하면 동일하다.

숫자는 그대로 두고 금리 인하 확정·종전/시설 복구 완료·관세 전면 철폐라는 허위 주장을 넣은
별도 반례에서는 **세 주장 모두 거절하고 게시 보류**했다.
[반례 결과](evidence/briefing-content-20260922/adversarial-result.json)는 설계한 한 사례의 결과이며,
일반적인 오류 탐지율을 뜻하지 않는다. 본문 길이도 품질 점수가 아니다.

독립 검토는 작성자·정책 버전·이전 점수를 알려주지 않은 다른 모델의 평가다. 인간 애널리스트
평가나 거래소 원시 데이터의 진위 확인을 대신하지 않는다. 같은 사례에서 누락을 발견하고
고친 **개발 결과**이며, 처음 보는 날짜에서의 성능으로 보고하지 않는다.

## 부실함을 줄인 변경

- **수집 범위:** 최신 단신 순서에만 의존하지 않고 마감 보도, 정책·거시, 국제 정세, 기업·업종,
  자산 간 흐름과 출처 다양성을 나누어 읽는다. 원문 최대 16건, 각 3,000자라는 한도와 누락 기록을 유지한다.
- **본문:** 핵심 세 줄 뒤 시장 전체 흐름, 주요 숫자, 최대 여섯 주요 이슈의 배경·영향, 다음 확인
  사항을 둔다. 중요한 이야기를 세 건으로 자르거나 분량 때문에 스레드로 밀어내지 않는다.
- **내용 검사:** 모든 원문에 반영/배경/제외 이유를 요구한다. 사실·숫자가 맞아도 중요한 누락,
  얕은 설명이나 나쁜 가독성이 있으면 정상 품질로 통과시키지 않는다. 실제 본문 미리보기를 검사한다.
- **보완:** 첫 검토에서 문제가 확인되고 시간이 충분하면 같은 원문으로 한 차례 고치고 다시
  검토한다. 원문·초안·지적·수정 결과와 실패를 보존하고, 응답 불명을 새 요청 ID로 우회하지 않는다.
  확인 조건만 문제인 경우에는 해당 문장만 실제 모델이 고치고 서비스가 나머지 내용을 보존해
  재검토한다. 저녁판의 마지막 수정은 이 경로로 수행했다. 조건 수정 전후의 사실·수치는 동일하다.
- **검증기 수정:** 실제 출력에서 발견한 정확한 단위 변환, 영어 수량 표현, 등락 부호·단위,
  가상자산 관측일, 중첩 JSON 줄바꿈의 오판을 수정했다. 의미가 다른 주장이나 바뀐 인용문은
  그대로 거절한다. `G7` 같은 이름의 의미 확인은 별도 검토가 담당한다.
  한 문장의 근거가 여러 기사에 걸칠 때 모든 출처 번호를 보여주도록 인용 표시도 수정했다.

## 실패도 보존했다

이전 작성 지침은 같은 입력에서도 중요한 AI 이슈의 인용문을 다른 기사에 붙여 해당 이슈가
제외됐다. 초기 새 아침판은 여섯 이슈를 썼지만 제공된 핵심 지수를 구조화하지 않아 축약판이었다.
초기 저녁판의 별도 검토는 시각을 모르는 미국 현지 행사를 한국의 ‘오늘 밤’으로 단정한 문장을
거절했다. 보완본에서도 잘못 붙인 날짜 근거와 인용문 문장부호 때문에 내용이 제외되는 실패가 있었다.

잘못된 출력을 교체하거나 숨기지 않았다. 초기 작성·검토·보완, 검증기 수정 전후의 평가는
[증거 디렉터리](evidence/briefing-content-20260922)에 남겼다. 이전 작성 지침과의 비교는 같은
새 입력을 사용한 작성 단계 비교이며, 수집부터 발송까지 전체 시스템의 무작위 비교는 아니다.

첫 이전판의 Claude 검토는 `uncertain`으로 끝나 보존했고 새 ID로 다시 실행하지 않았다.
마지막 저녁 검토의 최초 전달은 중지된 worker 때문에 Python/HTTP 실행 전에 거절됐다.
런타임 영수증 부재와 이 오류를 대조한 뒤 **같은 요청 ID와 같은 본문**으로 기존 일반 worker를
통해 회수했다. [전달 대조 기록](evidence/briefing-content-20260922/pm-review-transport-reconciliation.json)을 남겼다.
조건 수정의 첫 호출은 추론 시작 전 `busy`로 거절됐고 같은 ID로 재개했다. 총 19개 고유 요청의
완료 응답과 이전판 검토 1건의 불명 응답을 보존했다. 준비만 하고 실행하지 않은 요청은 별도로 표시했다.

## 검증 범위와 한계

원문은 아침 07:10 KST 이전 발행·수집본과 오후 16:57 KST의 장 마감 후 수집본이다. 각 판의
16개 발췌, 원문/발췌 해시와 시각은 [입력 기록](evidence/briefing-content-20260922/source-snapshots.json)에 있다.
오후 사례는 정시 20:00 발간 검증이 아니다. 과거 입력에 오후 기사나 현재 조회한 레이크 값을
소급해 넣지 않았다. 이 내용 평가는 뉴스 원문을 사용했으며, 레이크와 합친 정시 종단간 운전은 별도다.

작성·의미 검토는 기존 Codex 구독 런타임에 `gpt-6-astra/high`를 요청했다. 다른 모델의 내용
평가는 기존 Claude 구독 런타임의 `claude-opus-5/max` 요청이다. 실제 provider·usage 영수증을
보존하며, effort 요청과 제공자 확인을 구분한다. 새 유료 API, 모델 도구 호출, Slack 게시와 운영
설정 변경은 하지 않았다. 평가용 Claude 검토가 매 정기 발간마다 실행되는 것은 아니다.

모든 변경을 포함한 최종 전체 회귀 **1,070개 통과·36개 건너뜀**, 브리핑
전체 검사 **83개 통과**를 확인했다. 실제 로컬 PostgreSQL·Temporal을 사용했고 이 테스트의 모델과
Slack은 모의다. 별도로 기록한 실제 구독 모델 평가와 혼동하지 않는다.
[검사 집계](evidence/briefing-content-20260922/regression-summary.json),
[패키지 대조](evidence/briefing-content-20260922/package-check.json)에 범위를 기록했다.
Ruff·lock 검사는 통과했고 wheel 안의 소스 138개가 작업 파일과 일치했다.
[최종 검증 영수증](evidence/briefing-content-20260922/validation.json)에 코드 해시와 인수 경계를 모았다.

**전문가 수준을 입증했다는 결론은 아직 내리지 않는다.** 독립 검토의 보완 의견, 제한된 출처와
시점, 동일 사례를 이용한 수정, 인간 평가 부재를 함께 고려해야 한다. 새 거래일의 5일 미리보기,
핵심 시세의 수집/복수출처 확인, 실제 Slack 전달도 미검증이다. 기본 게시 설정은 꺼져 있다.
운영 인수와 복구 절차는 [브리핑 안내](../briefing.md), 결정 배경은 [ADR 0037](../adr/0037-substantive-briefing-evaluation.md)을 따른다.

이후 다른 거래일의 첫 아침판에서 정책 기준·반대 근거 누락을 실제로 발견하고 편집 규칙을
수정했다. 그 결과와 미완료된 검증은 [후속 검증 기록](BRIEFING-HELDOUT-VALIDATION.md)에 별도로
남긴다. 이 페이지의 9월 22일 통과 수치를 후속 정책의 통과 수치로 소급하지 않는다.
