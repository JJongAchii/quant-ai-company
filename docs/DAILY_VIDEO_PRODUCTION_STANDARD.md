# 뭐든story DAILY VIDEO PRODUCTION STANDARD v1

2026-10-06 · 아침 시장 브리핑 시리즈

역사·스토리 영상 제작 기준은 별도 유지한다. 이 시리즈는 사용자의 요청에 따라 정리된 글을
화면의 주인공으로 삼는다. 기존 기준의 사실 정확성, 출처, 음성 품질과 최종 검토 원칙을 이어받는다.

1. **원본:** Slack에 발송된 AM·PM daily brief **본문만** 동결한다(v2, 2026-10-10). 기사 원문·수집 묶음·초안은 쓰지 않는다.
   '일부 확인 중' 축소 본문도 본문이면 영상을 만든다. 본문 없는 대체 공지는 영상을 만들지 않고 brief 스레드에 알린다.
   영상 제작 중 새 시세·뉴스를 추가하지 않는다. 매체 1곳 인용 문장은 "보도에 따르면", 정규장 종가는 "정규장 종가 기준",
   수급은 "장 마감 기준"을 표시하고, 화면·설명에 제작 도구(AI·모델·음성 서비스) 문구를 쓰지 않는다.
2. **구성:** 오늘의 한 문장 → 시장 연결 → 주요 이슈와 반대 근거 → 다른 중요한 이슈 →
   다음 확인 조건. 11~15장면(최대 16), 4~5분을 목표로 하되 자료가 부족하면 짧게 끝낸다. 반복으로 길이를 채우지 않는다.
3. **화면:** [아침 시장 브리핑 디자인 명세](DAILY_BRIEF_DESIGN_SPEC.md)를 따른다. 1920×1080·30fps,
   고정 화면 틀(상단 바·진행선·카드 무대·자막 띠·티커), 정해진 카드 종류, 모션·색·글꼴·이미지 규칙은 명세가 정한다.
   화면에는 그날 원문 숫자만 쓰고 원문에 없는 계산·시계열을 만들지 않는다.
4. **주장:** 사실·가능한 해석·확인 조건을 구분한다. 반대 근거와 제약을 보존한다.
   화면과 내레이션의 숫자·단위·부호·비교 기준·자료 시각을 원본과 맞춘다.
   계산은 기존 brief에서 검증한 동일 계산만 사용한다. 투자 성과와 가격을 단정하지 않는다.
5. **제목:** 제목·썸네일·도입이 같은 내용을 약속해야 한다. 본문에 없는 수익·확정 전망을 넣지 않는다.
6. **음성:** 한국어의 금융 용어·영문 약자 발음을 정리한다. 장면별 음성 task ID를 남긴다.
   재생산에 비용이 드는 요청은 확인된 실패/미실행 근거 없이 재요청하지 않는다.
7. **자막과 시간:** 실제 음성의 word timestamp로 자막·챕터를 만든다. 글자 수로 재생시간을 추정하지 않는다.
   transcript 일치와 숫자 검사 실패는 청취 검토가 필요한 보류다. 자동 ASR로 의미 정확성을 확정하지 않는다.
8. **완성 검사:** 화면 잘림·해상도·오디오 포함·실제 길이·전체 decode·검은 프레임·장시간 무음·음량을 검사한다.
   기술 검사를 통과해도 공개 전 전체 시청을 거친다.
9. **게시:** 기본(`VIDEO_UPLOAD_ENABLED=false`)은 완성 파일(MP4·썸네일·SRT·upload.txt)을 brief 스레드로 전달하고
   소유자가 전체 시청 후 직접 올린다. YouTube API 업로드를 켜면 먼저 비공개 업로드하고, owner/channel/message
   receipt/version/file hash가 일치하는 Slack 공개 승인만 받는다. 수정하면 새 버전으로 검토하며 이전 버튼은 무효다.
10. **시각과 비용:** 유튜브 공개 10분 전(아침 06:50, 11월부터 07:40 · 마감 17:50 KST) 파일 준비를 목표로 하며, 지연 시 상태를 알린다. 09:00 KST 공개 승인은
    만료된다. 크레딧 한도와 기존 계정 잔액을 검사하고 자동 충전·API 전환을 하지 않는다.

첫 비공개 샘플에서 확정할 항목은 목소리, 한국어 숫자·고유명사 발음, 화면당 읽는 속도,
핵심 문장 밀도, 제목/썸네일 톤과 채널의 공개 권한이다. 코드 기본값을 채널의 최종 승인으로 해석하지 않는다.
