# ADR-0012: 회사 서비스를 독립 저장소로 관리

상태: 사용자 선택으로 확정, 2026-09-16.

## 결정

사용자가 선택한 비공개 `JJongAchii/quant-ai-company`를 회사 서비스의 정본으로 둔다.
패키지·CLI·운영 경로 이름 `quant-company`는 유지한다. `quant-workspace`는 공통 연구
규약·스킬·qws 계약을 관리하고, `quant-data`는 별도 데이터 라이브러리로 유지한다.

기존 `services/quant-company`의 Git 이력은 `git subtree split`으로 보존한다.
경로 이동에 따라 SHA가 바뀌므로 원본 커밋과 추출 커밋은 `REPOSITORY-MIGRATION.json`에
기록한다. 과거 검증의 원본 커밋·digest는 고치지 않는다. 초기 이관은 운영 배포가 아니다.

## 이유

상시 서비스는 연구 워크스페이스와 릴리스·권한·운영 수명주기가 다르다.
개선 BOT의 GitHub App을 이 저장소에만 설치해 공통 연구 규약이나 데이터 수집 저장소에
쓰기 권한을 주지 않는다. 저장소 안에서도 변경 경로와 CI·배포 권한을 제한한다.

## 운영 경계

현재 Slack·DB·Temporal·Codex 인증은 서버에 있다. 맥북 전원은 실행 의존성이 아니다.
맥북을 실제로 껐다는 추가 시험 기록이 없다는 이유로 운영 기능을 미완료라고 표시하지 않는다.
장시간 부하와 장애 관찰은 계속한다.

개선 BOT은 수정·테스트·PR까지 자동화하고 운영 반영은 사람 검토 후 진행한다.
새 저장소 생성이나 CI 통과가 자동 merge·deploy를 실행하지 않는다.
