# 0027: hot-news 연속 수집과 Reporter

날짜: 2026-09-18. 상태: 구현, 로컬 및 실제 구독 자격 검사 완료; 운영 활성화 전.

## 요구

사용자는 `hot-news`에 중요한 경제·거시경제·국제 정세 소식이 검증 후 수시로 올라오기를 원한다.
08시·20시 정기 발송은 의도와 다르며, 정기 브리핑은 추후 `daily-brief`에서 한다.
별도 기자 느낌의 봇은 Reporter로 정했다.

## 결정

독립 Slack 앱 identity를 추가하고 기존 서버·PostgreSQL·Temporal·공식 구독 모델 실행기를 공유한다.
RSS/Atom 수집은 모델 작업과 별도 Temporal queue에서 진행한다. 기사 버전·원문 근거·수집 건강도는
PostgreSQL에 저장하며, 검토는 기존 사용자 업무·공통 호출 한도·모델 동시 실행 1개 제약을 따른다.
메모리 큐나 OS cron을 신뢰하는 발송 구조를 추가하지 않는다.

등록된 소스의 공개 HTML/text 원문을 기사 영역 기준으로 추출한다. 편집 모델은 동결된 요청 ID와
근거 묶음을 받아 `NewsReview` JSON 한 개만 제안한다. 도구·메시지·위임은 허용하지 않는다.
서비스가 인용·원천·ID·시각·정책을 검사하고 사건·메시지·outbox를 한 DB 트랜잭션에서 기록한다.
소유자·채널·소스·게시 정책이 달라지면 기존 결과를 발송하지 않는다.

초기 검토 대상은 최근 2시간, 재개 시 최대 24시간이다. 보류 기사는 새 근거가 있을 때 재검토한다.
같은 URL의 의미 있는 변경은 기존 사건의 스레드로 보낸다. 사건 통합의 의미 판단은 모델이 맡으며
전체 세계 사건의 완전한 중복 제거를 보장하지 않는다. 미리보기 기사는 게시 활성화 후 재생하지 않는다.

원격 호출의 불확실성은 영수증과 함께 보존한다. 모델 요청을 새 ID로 자동 재발행하거나
Slack 결과 불명의 메시지를 자동 재전송하지 않는다. Slack의 성공 응답에 `ts`가 있어야 뉴스의
원 글을 전달 완료로 표시하고, 그 후에만 후속 글을 스레드에 연결한다. 정확히 한 번 전달을 주장하지 않는다.

수집과 요약 이용 설정을 구별한다. 민간 매체는 이용 범위가 미확정인 동안 제목·URL·시각을
조사하는 상태다. 유료 API 계약·우회 수집은 추가하지 않는다. 현재 활성 가능한 공식자료만으로
글로벌 뉴스 전체를 포괄한다고 주장하지 않는다.

## 결과와 한계

새 앱 manifest, 미리보기·상태 도구, 별도 뉴스 스레드 응답 경로를 제공한다. 기존 네 직원은
뉴스 기능을 끈 기본 설정에서 그대로 동작한다. Reporter는 자동 직원 교육 일정에 포함하지 않는다.
실제 연준 원문 검사에서 메뉴가 본문을 밀어낸 문제를 발견했고, 기사 영역 추출로 수정했다.
원문이 없을 때 보류하는 실제 모델 결과와 수정 후 게시 후보 결과를 모두 보존했다.

수치·주장의 의미상 지지와 독립 원천 판단은 모델의 오류 가능성이 남는다. 실제 Slack,
운영 배포·장시간 부하·글로벌 보도 누락률은 아직 검증하지 않았다.
