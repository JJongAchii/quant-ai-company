# 0032: AI를 사용하지 않는 tech-feed

날짜: 2026-09-21. 상태: 구현 및 검증 중.

사용자는 개발·연구 중심으로 폭넓은 기술 소식을 원하지만 요약·추가 AI 비용을 원하지 않는다.
한국어·영어 원문을 함께 받고, KST 06~24시에 수시 발송하며 대표 소스부터 시작하기로 했다.

기존 HTTP 수집 및 outbox를 공유하는 독립 `tech_feed` 모듈을 둔다. 기술 RSS는 원문 설명과 링크만
전달하고 기존 hot-news의 원문 검토·검색·모델 편집 경로를 사용하지 않는다. 모델 사용량을 줄이기 위한
프롬프트 대신 모델 호출과 업무 생성 자체가 없는 실행 경로를 제공한다. Reporter identity는 공유하되
이 채널의 Reporter 멘션·댓글은 자동 AI 답변을 만들지 않는다.

소스 선택은 검토된 JSON과 출처별 분류/경로 필터로 결정한다. PostgreSQL이 최초 기준점·중복·발송 간격·
영수증을 소유하고, 별도 Temporal workflow가 수집·재시도·타이머를 소유한다. 최초 기준점 이후 최근
72시간의 새 글만 발송하며 미리보기·과거 글·불명 발송을 재생하지 않는다. 제목·설명 변경은 새 사건이 아니다.
비교적 큰 기술 블로그 피드에만 최대 2MiB를 허용하고, CDATA 안의 HTML 코드 예제와 실제 XML DTD를 구분한다.
기존 news parser의 기본 크기·파싱 정책은 유지한다.

테스트는 실제 PostgreSQL·Temporal과 모의 Slack을 구분한다. 실제 공개 소스 및 운영 Slack 영수증은
`docs/project/evidence`에 남기고 도입 상태는 프로젝트 인수 문서에 기록한다.
