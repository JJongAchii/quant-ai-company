# ADR-0026: Claude 구독으로 직원 답안의 독립 검토 연결

2026-09-18. 사용자가 Claude Pro 구독, 추가 사용량 과금 비활성화, 공식 로그인 완료를
대화에서 확인했다. 기존 직원 전문성 개선 요청의 연결 단계이며 qws 계약을 변경하지 않는다.

## 결정

- 직원 풀이와 객관 채점은 기존 Codex·Python 경로를 유지한다. Claude는 답안 설명의
  근거·추론·중요 가정·한계를 검토한다. 작성자/작성 모델/기존 점수/정답표를 전달하지 않는다.
  새로운 웹 검색은 이 평가에 쓰지 않는다. 실제 업무의 웹 조사 기능은 기존 별도 경로다.
- 기존 서버에 별도 `claude` Compose profile을 둔다. 공식 Claude Code 2.1.275,
  `claude-opus-5`, effort high를 고정한다. 기본 모델 별칭·fallback·fast mode·1m 모델
  선택을 쓰지 않는다. CLI 버전과 공식 Pro/Max 로그인, 실제 반환 모델을 각각 검사한다.
- 계정 소유자가 usage credits/extra usage를 껐다는 확인을 활성화 조건으로 받는다.
  이 플래그는 서버가 계정의 결제 설정을 조회하거나 잠갔다는 뜻이 아니다. API·프록시·
  대체 클라우드 인증 환경을 거부하며 유료 API로 자동 전환하지 않는다. CLI의 costUSD는
  API 상당액 추정치라 실제 구독 청구액으로 저장/표시하지 않는다.
- 모델에는 회사 DB/Slack/AWS/유지보수 키와 연구 파일을 주지 않는다. safe mode,
  빈 도구/MCP/설정, 임시 작업 디렉터리를 사용한다. JSON 반환용 StructuredOutput만 허용한다.
- DB에 입력과 원 답안 digest를 먼저 고정하고 실행기에는 호출 전 durable receipt를 쓴다.
  완료 결과는 같은 ID로 재사용한다. 명시적 quota는 같은 입력으로 지연하고, 불확실한
  중단은 자동 재추론하지 않는다. 모델 영수증은 DB와 같은 정지 구간에 백업한다.
  인증 파일은 백업에 넣지 않는다.
- 기존 Temporal 직원 개발 루프에서 일반 업무와 문제 풀이 다음에 최대 하루 2건을 검토한다.
  11명 모두 매일 평가하는 일정으로 바꾸지 않는다. 서로 다른 계정이어도 서버 용량은 공유하므로
  Claude 동시 호출은 1개, 컨테이너 메모리 상한은 512 MiB로 제한하고 실제 사용량을 측정한다.
- 독립 결과는 `not_yet_calibrated` 보조 의견이다. 객관 점수·직원 역량·자동 수정/승격 기준을
  덮어쓰지 않는다. 모든 차원의 인용이 제공된 자료에 실제로 있는지 검사한다. 원 과제에 이의가
  제기되면 이전 검토 결과를 현황에서 숨긴다. 개선 BOT은 검토기·채점기·승격 기준을 수정할 수 없다.

## 평가 기준과 한계

연결 확인용 실제 Opus 호출은 정상 산술 답안에도 기수/모듈러 연산 가정을 명시하지 않았다는
불필요한 지적을 냈다. 이를 정답 채점 실패로 반영하지 않았다. 루브릭을 수정하여 결과에 영향을
주는 누락만 지적하고, 일반적인 수학·업무 관행을 매번 설명하도록 요구하지 않게 했다.
연결 테스트와 소수의 sanity check는 평가 정확도 검증이 아니다.

향후 실제 업무의 정답/오답/정보 부족 사례 30~50개를 별도 기준으로 확인하고 정상 답안 오판,
중대 오류 누락, 판단 불가를 비교한다. 기준 조정 사례와 평가 사례는 분리한다. 모델 계열이
다르다는 이유만으로 우수한 평가자 또는 직원 전문성 향상이 입증됐다고 주장하지 않는다.
