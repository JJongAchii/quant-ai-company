Status: accepted for implementation; actual model and Slack acceptance pending.

The owner asked for the Analyst bot to perform the briefing with professional analytical depth.
Rename the dedicated role's visible identity to Analyst / 애널리스트 while retaining `market_brief` as the
technical role, Slack credential key and routing identity. Keep 07:30/20:00 KST delivery and the existing
financial-strategist handoff. A manifest update does not itself rename an installed Slack application.

Require each issue to contain an evidence-backed mechanism and competing explanation, a horizon and an
explicit basis (reported explanation, conditional hypothesis or unresolved). The main interpretation stays
short; detailed analytical conclusions go in the thread. The existing next checkpoint must distinguish
explanations or identify an observation that would weaken/change the view. Do not request hidden reasoning.

Extend review from six to nine required checks with transmission, alternatives and falsifiability. All
analytical claims participate in the same quote, number, item-ID, rejection and pruning contracts as other
claims. Rejecting an essential analysis claim removes the issue. Semantic reviewers must also reject any
dependent summary claims; numeric validity alone cannot establish economic causality.

Freeze the professional procedure and attributable practice feedback with the edition. Both scheduled
writer and reviewer receive the same procedure used in follow-up conversations. Include its digest in
policy identity and bump the publication format to v3. Historical v2 records remain readable stored messages,
but do not qualify as current v3 analysis. No automatic replay of historical publication is introduced.

Add Analyst to the existing bounded staff practice rotation with two new named synthetic families:
macro surprises/causality and earnings/FX/breadth. Existing employees' question families are unchanged.
Keep fixed numerical/defect oracles server-side; feedback reaches future frozen briefing inputs. The
practice process yields before new inference during briefing preparation and uses existing limits.
Add official-document reading and financial calculation tools for follow-up questions, retaining no
delegation, scheduling, trading, model-training or configuration authority.

This implementation adds procedure, inspectable reasoning summaries, review and measured practice. It
does not certify analyst-level professional competence, train model weights or prove live editorial quality.
Real model exercises, independent explanation review and live briefing acceptance remain separate evidence.
