# ADR-0015: 개선 제안 봉투의 근거 인용 검증

2026-09-17, 채택.

운영 인수에서 Codex가 실제로 제공된 메시지 ID를 제안 artifact의 `source_ids`에도 인용했다.
본문은 개선 제안 스키마를 따랐지만 검사기가 빈 목록만 허용해 `invalid_maintenance_proposal`로
정지했다. 모델 안내에는 이 빈 목록 제약이 없어 입력·검사 계약도 불일치했다.

제안 artifact는 구조화된 개선 제안을 전달하는 봉투다. 여기에 적힌 출처는 해당 호출에 제공된
관찰·역사 근거·수정 근거의 정확한 ID일 때만 허용한다. 생략된 근거와 알 수 없는 ID는 거절한다.
본문 Finding의 근거·고정 평가 기준 검사, 위임·도구·메모리 등 실행 금지 조건은 계속 적용한다.

이미 정지한 작업은 자동으로 재시작하지 않는다. 운영자가 원래 응답과 근거를 대사하고 명시적으로
재개 기록을 남겨야 한다. 응답·호출 ID는 보존하며 모델을 다시 호출해 결과를 바꾸지 않는다.
기준 커밋이 이동했다면 선택 파일이 같은지 별도로 검토한 뒤 새 스냅샷으로 재개한다.

검증: 실제 장애와 같은 봉투 인용, 역사·수정 근거 인용, 알 수 없는/생략된 근거 거절,
유효 인용이 있어도 잘못된 decision 상태 거절을 `test_maintenance_proposals.py`에서 검사한다.
