# ADR-0021: 출처가 남는 공식 금융자료 읽기

상태: 2026-09-17 승인된 후속 읽기 기능 구현.

## 범위

첫 경로는 KRX·FINRA·SEC Investor.gov·연준·BIS의 선정 문서 7개를 찾는
`finance_search`와 허용 기관의 실제 HTML 원문을 가져오는 `finance_read`다.
일반 검색엔진·뉴스 수집·PDF·유료 자료·로그인 자료·개인 연구 파일 접근은 포함하지 않는다.
공식 문서의 URL을 지정해 읽을 수도 있다. 후보 목록은 읽은 근거나 금융 전문성 인증이 아니다.
개선 BOT의 PR #16이 제안한 범용 웹 검색 기능 전체를 완료했다고 표시하지 않는다.

## 출처 계약

- 검색 후보에는 source_id를 부여하지 않는다. 원문을 성공적으로 읽은 경우만 출처가 된다.
- 원 HTML, 응답 byte hash, 정규화 본문, URL, 기관·관할, 조회 시각을 보존한다.
- 명시된 발행·수정 메타데이터만 기록한다. 없으면 null이며 HTTP Last-Modified를 발행일로 바꾸지 않는다.
- 현재 조회했다는 사실이 과거 시점 가용성이나 현행 제도의 독립 검증을 보장하지 않는다.
- 출처는 프로젝트에 한정한다. 바뀐 본문·새 조회는 새 버전이며 기존 인용을 덮어쓰지 않는다.
- 반환 본문은 12,000자씩 읽고 next_offset을 제공한다. 전체 추출 한도는 80,000자이며 잘림을 표시한다.
- 공식 기관의 미국 상품 설명을 한국 제도 근거로 사용하지 않도록 관할을 함께 전달한다.

## 실행 경계

허용된 정확한 HTTPS 호스트·443 포트만 접속한다. DNS 결과를 공인 IP로 확인하고 그 IP에
직접 연결하되 원래 호스트의 TLS 인증·SNI를 사용한다. 리다이렉트도 다시 확인하고 다른
호스트 이동은 거절한다. 프록시·쿠키·서버 비밀정보는 전달하지 않는다.
응답 1MB·리다이렉트 3회·연결/읽기 시간 제한과 업무당 도구 호출 제한을 적용한다.
자료 본문은 지시 권한이 없는 데이터다. 임의 코드 실행이나 도구 권한 변경을 허용하지 않는다.

HTTP는 업무 DB 잠금 밖에서 수행한다. 조회 결과는 turn ID와 요청 digest로 보존하고,
최종 반영 시 현재 지시 버전과 후속 입력 대기를 다시 검사한다. 중단 중 도착한 원문은
조회 이력으로 남지만 해당 업무의 출처·답변으로 게시하지 않는다.

## 검증

CI는 실제 PostgreSQL과 모의 HTTP로 권한·버전·중단 경쟁·캐시 재시도·출처 격리를 검사한다.
실제 공식 사이트 접근, 실제 모델의 자료 해석, Slack 전달은 별도 인수 기록으로 구별한다.
403·실패·미지원 형식에는 성공 출처를 만들지 않는다. 접근 제한을 우회하지 않는다.
