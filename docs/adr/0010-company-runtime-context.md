# ADR-0010: 회사 BOT에 실행 설정을 전달한다

- 날짜: 2026-09-16
- 상태: 기존 회사 서비스의 구현 보완
- 관련: ADR-0009, `docs/work/quant-ai-company/INTENT-v1.json`

## 문제

실제 Slack에서 총괄에게 직원별 LLM 모델을 물었으나, 모델 호출을 만드는 서버만 모델 배치를
알고 있었다. BOT에는 임무·도구·업무 기록만 전달했고 출처 저장소에도 운영 설정이 없었다.
이 때문에 불필요한 지식 검색 후 사용자에게 모델 설정을 제공해 달라고 요청했다.

## 결정

`Company.prepare_turn`은 실제 로드한 역할과 설정에서 비밀이 없는 필드만 골라
`RUNTIME CONFIG JSON`으로 전달한다. 직원 ID·이름·활성 여부·설정 모델·역할 버전·도구·위임
권한과 서비스 실행 한도를 포함한다. 출처 검색과 인터넷 검색, 산술과 코드 실행의 차이도 명시한다.
설정 전체를 직렬화하거나 자격 증명 파일을 읽지 않는다.

이 정보는 사용자·자료의 내용과 구분되는 서버 생성 설정이다. BOT은 운영 모델 질문에 이 값을
직접 사용하며, 비활성 역할을 운영 중이라고 말하거나 직무 이름에서 실행 능력을 추론하지 않는다.
설정 모델 ID는 제공자 내부 모델 배포에 대한 독립 증명이 아니다. 실제 금융 전문성도 별도 검증이다.

## 검증과 재시도

외부 역할 파일의 재정의, 비활성 역할, 비밀 값 제외, 사용자 메시지와의 분리, 재시도 시 기존
요청 보존과 새 요청에서의 설정 반영을 검사한다. 저장된 요청을 소급 수정하지 않으므로 새 요청부터
이 정보가 포함된다. 실제 모델 답변 검사는 Slack 발신 없이 내부 검증 프로젝트에서 수행한다.
