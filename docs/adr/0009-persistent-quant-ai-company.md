# ADR-0009 — 맥북과 세션에서 독립된 Quant AI Company

- 날짜: 2026-09-16
- 상태: 첫 서비스 구현 승인·로컬 검증 단계. 외부 배포와 전체 연구 조직 인수는 미완료.
- 범위: 개인 퀀트 연구 조직의 상시 실행·Slack 협업·전문 직원
- 명세: [회사 아키텍처](../work/quant-ai-company/ARCHITECTURE.md)

## 배경

사용자는 세션 안에서만 실행되는 기존 멀티에이전트 구조를 넘어, 전문 BOT이 서로 직접 논의·위임·공유하고
사용자가 언제 어디서든 함께 일하는 조직을 요청했다. 맥북의 가동 여부와 무관하게 Slack에서 협업하고,
금융 전반에 깊은 지식을 가진 BOT을 갖추어야 한다.

대상 연구는 국내 시장 일·월, 글로벌 시장 일·월, 가상자산 중빈도·고빈도·일 등이다.
기존 Quant의 자산은 검토 후 활용하되 현재의 조직과 세션 구조를 완성된 설계로 가정하지 않는다.

## 결정 및 확장 방향

1. Slack을 기본 업무 공간으로 삼고 직원별로 멘션·DM 가능한 bot identity를 둔다.
2. 신규 상시 클라우드 서비스가 직원의 업무함·책임·기억·예약 업무를 유지한다. 맥북은 접속 단말이다.
3. 총괄은 사용자 의도·우선순위를 유지하고, 전문 직원들은 프로젝트에서 직접 소통·위임한다.
4. 국내·글로벌·가상자산 연구팀의 담당자를 분리하고 금융전략·데이터·개발·검증·리스크·운영을 공유한다.
5. 금융지식·투자전략 BOT에 폭넓은 금융 자료·계산 도구·최신 정보·전문 시험을 함께 구성한다.
6. Temporal은 영속 실행을, PostgreSQL은 회사 도메인 상태를, S3/Git은 산출물을 소유한다.
7. LLM은 Codex CLI/SDK 또는 공식 API 어댑터로 연결하며 직원 identity와 분리한다. 사용자의 기존 Pro 20x
   정보를 반영해 첫 운영은 구독 활용을 우선 제안한다. 초기 모델 배치는 실제 역할 평가로 수정한다.
8. 사용자 지시 revision, inbox/outbox, 작업 소유권, 비용 예약, 외부 작업 대사로 장시간 업무를 유지한다.
9. 기존 데이터·계산·검증 코드는 어댑터로 연결한다. 세션 워크플로 전체를 새 회사의 통제 구조로 옮기지 않는다.
10. 첫 인수는 실제 Slack 직접 협업·중간 개입·맥북 종료·프로세스 재시작을 포함한다.
11. 초기 비용을 줄이기 위해 회사 서비스·PostgreSQL·Codex 실행기를 단일 VPS에 통합한다.
    외부 백업과 Temporal 종량제는 유지하고 이중화는 확장 단계로 둔다. 서버 장애 시 복구 중단을
    명시하며, [최소 비용안](../work/quant-ai-company/MINIMUM-SERVER.md)의 부하·복원 검증을 거친다.
12. 사용자 AWS 선택과 도메인 부재를 반영해 서울 Lightsail 4GB·Slack Socket Mode로 시작한다.
    HTTP 수신과 Caddy는 선택 구성이다. 기본 공개 포트는 운영자 IP의 SSH만 허용한다.

## 대안과 선택 이유

- **기존 세션 구조 확장:** 현재의 직원·업무 수명이 맥북이나 주 대화에 연결되는 문제를 해결해야 한다.
- **Paperclip/OpenClaw 중심 확장:** 공개된 조직·대화·기억 기능은 유용한 재사용 후보다. 동작 부재를
  단정하지 않으며, 정한 인수 시나리오를 만족하는지 비교할 수 있다.
- **공식 SDK + Temporal + 회사 도메인 서비스:** 실제 Slack 직원, 연구 증거, 지시 변경·장애 처리의
  계약을 직접 통제할 수 있다. 구현·운영 비용이 추가되지만 현재 요구에 대한 기본안으로 제안한다.

## 기존 규약과의 관계

회사 서비스를 구현하되 기존 실행·감사·승인 규약을 자동으로 변경하지 않는다.
3070 기본 실행, 작업별 명시 요청에만 5090 사용, 기존 EC2 콜렉터의 수집 전담은 유지하는 설계다.
상시 조직에서 감사까지 이어지려면 기존 “맥북 파일만 검사” 규약을 읽기 전용 클라우드 증거 검증으로
이관해야 한다. 이관 구현과 재현성 확인을 완료하기 전에는 그 단계까지 상시 동작한다고 주장하지 않는다.

사용자가 명시한 신규 조직 설계는 기존 세션 내 에이전트 증설과 목적이 다르다.
기존의 인프라 동결 권고를 이번 설계 요청을 거절하는 근거로 적용하지 않는다.

## 결과와 검증

직원과 업무는 특정 세션·모델 교체·맥북 종료를 넘어 유지되어야 한다. 동시에 대화 루프·중복 제출·
오래된 지시의 실행·근거 없는 금융 지식 축적을 방지하는 구현 책임이 생긴다.
운영 우월성이나 연구 성과는 아직 검증하지 않았다. [인수 명세](../work/quant-ai-company/BUILD-AND-ACCEPTANCE.md)로 확인한다.
