# ADR-0020: 회사 기록도 독립 저장소에서 관리

상태: 2026-09-17 사용자 지적을 반영한 정리.

## 문제

ADR-0012로 서비스 코드를 분리했지만 메인 구현 세션이 후속 배포·인수 기록을
quant-workspace의 회사 qws 브랜치에 계속 커밋했다. 회사의 현재 상태를 확인하려면
두 저장소를 봐야 했고, 독립 저장소라는 관리 의도와 맞지 않았다.
이 기록은 개선 BOT의 타 저장소 변경이 아니라 메인 구현 세션이 남긴 것이다.

## 결정

- 회사 코드, 설계, 로드맵, 운영·인수 검증은 quant-ai-company에서 관리한다.
- 기존 회사 전용 기록 중 빠진 문서·증거를 원본 그대로 가져오고 파일 해시와 원본 커밋을 기록한다.
- quant-workspace의 기존 qws 계약·과거 이력은 보존한다. 회사 후속 기록을 그곳에 추가하지 않는다.
- 원본 증거에 쓰인 SHA·경로·시각은 이관 시점의 새 검증으로 바꾸지 않는다.
- 회사 개선 BOT의 저장소 범위와 운영 승인 정책은 기존 ADR-0012·0016을 따른다.

검증: PROJECT-RECORDS-MIGRATION.json의 파일별 digest와 원본 Git blob을 비교한다.
이 정리는 문서 관리 수정이며 운영 코드의 배포를 의미하지 않는다.
