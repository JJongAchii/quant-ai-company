# 공식 금융자료 사용 범위

`finance_search {"query":"채권 ETF"}`는 선정한 기관 자료 목록에서 후보를 찾습니다.
`finance_read {"document_id":"finra-bonds"}`로 실제 원문을 읽거나, 허용 기관의 HTML URL을
`finance_read {"url":"https://…"}`에 지정할 수 있습니다.

허용 기관: 한국거래소 규정 안내, FINRA, SEC Investor.gov, 미국 연준, BIS.
일반 인터넷 검색·실시간 뉴스·상품별 공시 전수 검색·PDF는 아직 지원하지 않습니다.

답변은 실제 읽은 원문 링크, 조회 시각, 관할을 함께 제시합니다. 발행일을 확인할 수 없으면
확인 불가로 남깁니다. 접근 제한이나 원문 읽기 실패가 있으면 그 사실을 알립니다.
미국 상품 설명은 국내 ETF 제도·세금·거래 규정의 근거로 대체하지 않습니다.

긴 문서에는 다음 위치 `next_offset`이 반환되며 `read_source {"source_id":"…","offset":12000}`로
나머지를 읽습니다. 출처 승인 표시는 읽기가 허용된 기관 자료라는 뜻이며 내용의 독립 감사나
직원의 전문성 시험 통과를 뜻하지 않습니다. 같은 문서의 새 조회도 기존 인용을 덮어쓰지 않습니다.
