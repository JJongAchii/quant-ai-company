# 금융전략 BOT 개발 평가 자료

이 디렉터리는 **공개된 개발 사례와 출처 후보 목록**이다. 금융 BOT의 시험 성적이나
검증된 지식 저장소가 아니다. 이 자료로 프롬프트를 수정한 뒤 같은 사례를 맞혔다고
미지의 문제에 대한 전문성을 입증했다고 보고하지 않는다.

- `financial-cases.json`: 가상 수치로 만든 계산 5건, 시점·현재성·반복 주장·문서 내 지시 4건.
- `source-catalog.json`: 확인할 공식 자료의 진입점. 페이지 열기 성공과 금융 주장 검증은 별도다.
  Treasury 열기는 실패했고 ECOS는 텍스트를 추출하지 못했으므로 해당 상태를 그대로 기록했다.
- `test_financial_fixtures.py`: 정답 산술·단위·시간대·출처 상태를 검사한다. LLM 호출은 없다.

```bash
uv run pytest -q evals/test_financial_fixtures.py
```

## 실제 BOT 평가 방법

1. 같은 회사 서비스 경로로 금융전략 역할에 각 사례를 요청한다. 모델·역할 버전·커밋·사례
   digest·도구 영수증·최종 산출물을 함께 저장한다. 실제 실행 전에는 결과 칸을 채우지 않는다.
2. 산술값은 JSON의 `expected`와 단위를 대조한다. 계산 도구의 반환값을 검토했는지 확인한다.
   자연어의 숫자 일치만으로 맞았다고 판정하지 않는다.
3. 각 `rubric` 항목을 별도로 검토한다. 출처 ID 날조, 미래 자료 사용, 현재 금리 단정,
   의견의 자동 사실 승격, 자격증명 공개는 실패 사례로 보존한다.
4. 코퍼스·프롬프트·모델 변경 전후에 새 문제를 추가하고, 수정에 사용하지 않은 문제와 실제
   업무 산출물을 따로 평가한다. 판정자는 후보 답안을 생성한 실행과 분리한다.

현재 범위에는 채권 볼록성·옵션 비선형 위험·회계 연결 조정·시장 규제·대차·고빈도 체결의
전문 시험이 포함되지 않는다. 이 파일의 검증 통과는 **사례 파일의 정합성**만 뜻한다.
