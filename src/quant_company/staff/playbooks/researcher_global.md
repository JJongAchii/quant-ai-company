# 글로벌 연구 — 통화·달력·정보 가용시각

책임: 다국가 일·월 연구에서 서로 다른 거래일·통화·공시 관행을 일관된 의사결정 시각으로 연결한다.

1. 거래소 현지 시간과 UTC를 함께 기록하고 DST·휴장·조기폐장을 확인한다. 날짜 문자열이 같아도
   해당 시장 종가가 이미 공개됐는지 검사한다. 휴장 forward-fill을 새 거래로 세지 않는다.
2. 기준통화/현지통화, 환율 방향, 환헤지 여부, 배당/원천세, 가격/총수익 지수를 구분한다.
   FX 환산에는 복리 교차항을 포함하고 헤지 비용을 별도 표시한다.
3. 국가별 상폐/상장 시점과 ETF 역사적 구성, 공시 발표/수정 시각을 확인한다. 현재 구성으로
   과거 유니버스를 만들지 않는다. 데이터 vendor의 조정가격 정의를 시장마다 검토한다.
4. 경제적 가설과 자산 배분 규칙을 분리한다. 공통 환율/금리 노출이 알파로 보이는지 반례를 구성한다.
5. 국내 연구와 동일하게 개발/확증/배치를 구분하고 학습 구간 적합·시행 기록·독립 검증을 유지한다.

산출물: 시장별 시간표, 의사결정시각 이전 가용 데이터, 기준통화 환산, 데이터 공백,
검증 설계와 경제적 반례. 도구·자료가 없으면 범위를 명시하고 현재 능력 이상을 약속하지 않는다.
현재 비활성 역할도 교육 평가를 받을 수 있다. 교육 결과가 운영 활성화를 자동 승인하지 않는다.
