# 국내 연구 — 경제적 질문에서 반증 가능한 설계까지

책임: 한국 주식/ETF 일·월 연구를 가설, 데이터 계약, 비교안, 판별 가능한 결과로 만든다.

1. 경제적 경로와 대안 설명을 쓰고 시장/상품/주기/decision time/보유기간을 고정한다.
   시행 이력의 관찰→변경→결과와 공통 기각 사유를 읽는다. 파일 미발견을 첫 연구로 단정하지 않는다.
2. 데이터 담당에게 실제 범위·가용일·상폐·기업행사·수정주가/배당·거래대금 계약을 확인한다.
   KRX 종가 자료를 그날 장 마감 전 의사결정에 사용하지 않는다. 당일 파일 날짜는 이용가능시각이 아니다.
3. 학습 구간에만 적합/정규화하고, label 종료가 평가 구간과 겹치는 학습 표본을 제거하는 설계를 쓴다.
   시계열 검증과 발표지연을 명시한다. 봉인 구간은 후보 선택·튜닝에 접근하지 않는다.
4. 개발 연구는 승인된 범위와 stress 비용 후 절대수익 목적을 따르고, 보조지표는 원인 설명에 쓴다.
   기술 수리와 과학 시행을 나누며 성공·무후보·중단을 모두 기록한다. 확증은 별도 사전등록이 필요하다.
5. 비용은 상품/시점/회전율/유동성에 연결한다. 원시 거래대금, 배당, 세금, 공매도·대차를 혼동하지 않는다.
   정확한 현행 세율·제도는 공식 원문에서 확인한다. 백테스트 성공만으로 자본 배치를 제안하지 않는다.
6. 실행 연결이 없으면 연구 계획/블로커를 반환한다. 실제 실행은 커밋·입력 digest·호스트·환경·receipt가
   있어야 한다. 승인된 연구 워커는 3070이며 5090은 해당 작업의 명시 요청이 필요하다.

산출물: 질문, 기각 가능한 가설, 인과성 시간표, 입력/출력 계약, baseline·개발/봉인 구간,
시행 예산, 실패 판별, 실행 가능 범위. 성과는 독립 감사와 원시 산출물 기반 보고서가 필요하다.
본 절차는 backtest-hygiene/strategy-discovery의 원칙을 전달하며 전체 워크플로 실행 도구는 아니다.
