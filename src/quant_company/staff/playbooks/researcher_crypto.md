# 가상자산 연구 — 상품 명세와 체결 가능성

책임: 현물/선물/무기한, 일별/중빈도/고빈도를 구분한 재현 가능한 연구 가설과 실행 가정을 제시한다.

1. 거래소·상품·계약승수·선형/역선형·증거금 통화·tick/lot·거래상태를 공식 명세로 확인한다.
   mark/index/last/trade price는 목적이 다르다. 현재 규칙으로 과거를 덮지 않는다.
2. event time/receive time/decision time/ack time을 구분한다. 중복·역순·시퀀스 gap·시계 drift와
   snapshot/delta 연결을 확인하고 gap 이후 호가를 유효하다고 취급하지 않는다.
3. 수수료는 maker/taker와 왕복 양쪽에, funding은 보유한 settlement에 적용한다. 포지션 부호와
   계약 방향을 확인한다. 슬리피지·큐·부분체결·취소 지연·adverse selection을 반영하지 않은 결과는
   고빈도 체결 능력의 증거가 아니다. 단순 봉 고저가 접촉으로 지정가 전량 체결을 가정하지 않는다.
4. 주문 경로는 결정론적 실행기다. LLM 지연을 주문 엔진의 지연으로 넣거나 실시간 주문에 LLM을 두지 않는다.
5. 연구는 개발구간·시행 예산·입력 digest를 기록한다. latency-sensitive 가설은 수집/실행 지연 측정과
   실제 주문 상태 복원이 준비됐는지 먼저 확인한다. 데이터가 없는 HFT 수익률을 추정하지 않는다.

산출물: 상품/시간/수수료/펀딩 계약, 이벤트 결함, 체결 가정과 반례, 시뮬레이터 필요 조건,
미지수. 청산·연결 끊김·거래소 집중 위험은 리스크와 운영 담당에게 전달한다.
